## この補遺の役割

全11章では、仕組みを理解するために、重要な概念から順に説明しました。IPAシラバスには、同じ概念の別表記、古い機器名、特定方式の名称も数多く現れます。

この補遺は、シラバス用語の名前を見たとき、どの章のどの考え方に属するかを確認する辞書です。詳しい仕組みは各章へ戻ってください。

## 1　数、集合、統計、数理計画

### 1.1　数値表現

- **固定小数点数**：小数点位置をあらかじめ決めた数です。金額を銭単位の整数で持つ方法などがあります。 〈上位概念: 1.1　数値表現／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **単精度浮動小数点数**：一般にIEEE 754の32ビット浮動小数点形式を指します。倍精度より使用量は小さい一方、精度と範囲が狭くなります。 〈上位概念: 1.1　数値表現／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **倍精度浮動小数点数**：一般に64ビット浮動小数点形式を指します。単精度より多くの仮数・指数ビットを持ちます。 〈上位概念: 1.1　数値表現／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **パック10進数**：十進数字を一桁4ビット程度で詰めて保存し、最後に正負符号を持たせる形式です。十進の桁を正確に扱いたい業務システムで使われてきました。 〈上位概念: 1.1　数値表現／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **ASCIIコード**：英字、数字、記号、制御文字を7ビットの番号へ対応させた文字コードです。Unicodeの先頭部分はASCIIと同じ対応を保ちます。 〈上位概念: 1.1　数値表現／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉

### 1.2　集合と確率

- **積集合**：二つの集合の両方に含まれる要素の集合です。`A∩B` と書きます。 〈上位概念: 1.2　集合と確率／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **命題論理**：正しいか正しくないかを判定できる文を「命題」とし、その真・偽をAND、OR、NOTなどで組み合わせて考える論理です。たとえば「会員である、かつ、利用停止中ではない」のような条件を式にできます。 〈上位概念: 1.2　集合と確率／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **加法定理**：AまたはBが起きる確率を求める規則です。重なりを二度数えないよう、`P(A∪B)=P(A)+P(B)-P(A∩B)` とします。 〈上位概念: 1.2　集合と確率／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **乗法定理**：AとBがともに起きる確率を、条件付き確率で `P(A∩B)=P(A)P(B|A)` と求めます。独立なら `P(A)P(B)` です。 〈上位概念: 1.2　集合と確率／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **擬似相関**：二つの値に相関があっても、第三の要因が両方へ影響しているため、直接の因果がない状態です。 〈上位概念: 1.2　集合と確率／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉

### 1.3　計算とグラフ

- **掃出法**：連立一次方程式の係数を行基本変形し、未知数を順に消して解く方法です。ガウスの消去法とも関係します。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **重みつきグラフ**：辺に距離、費用、時間などの値である重みを持つグラフです。最短経路では重み合計を比べます。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **平均サービス率**：待ち行列で、窓口が単位時間に平均何件処理できるかを表します。到着率がこれ以上なら、長期的に列が増えます。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **連続最適化問題**：変数が実数の連続した値を取る最適化問題です。個数のように整数だけを取る離散最適化と区別します。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **逆ポーランド表記法**：演算子を値の後ろへ置く表記です。`3+4` を `3 4 +` と書き、括弧なしでスタック処理しやすくします。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **オーダー記号**：入力増加に対する計算量の増え方を `O(n)` などで表す記号です。O記法とも呼びます。 〈上位概念: 1.3　計算とグラフ／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉

## 2　AI、情報理論、信号、制御、センサー

### 2.1　機械学習の評価と学習

- **学習理論**：限られた学習例から、未知データにも通用する規則を学べる条件や誤差を研究する理論です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **凡化性能（汎化性能）**：学習に使っていない新しいデータへ、モデルがどれほど正しく対応できるかという性能です。IPAシラバスの「凡化」は、一般に「汎化」と表記されます。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 汎化性能〉
- **凡化誤差（汎化誤差）**：未知データに対する予測と正解のずれです。学習データ上の誤差だけを小さくしても、汎化誤差が小さいとは限りません。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 汎化誤差〉
- **バイアスとバリアンスのトレードオフ**：単純すぎるモデルの系統的な誤りと、学習データへ敏感すぎる揺れの釣合いです。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **AIのロバスト性**：入力の小さな変化、雑音、想定外状況、攻撃があっても、性能を大きく失わない性質です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **バックプロパゲーション（誤差逆伝播法）**：出力誤差を後ろの層から前へ伝え、各重みが誤差へ与えた影響を計算する学習方法です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 誤差逆伝播法〉
- **勾配消失問題**：深いニューラルネットワークで、前の層へ伝わる勾配が極端に小さくなり、学習が進みにくくなる問題です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **リカレントニューラルネットワーク（RNN）**：前の時点の内部状態を次へ渡し、文章や時系列の順序を扱うニューラルネットワークです。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: RNN〉
- **人間のフィードバックによる強化学習（RLHF）**：人が出力を比較・評価した情報を使い、望ましい応答へモデルを調整する方法です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: RLHF〉
- **ゼロショット学習**：対象例をプロンプト内に示さず、指示や既存知識だけで新しい課題を行わせます。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **フューショット学習**：少数の入出力例を示し、そのパターンに従わせます。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **インストラクションチューニング**：多様な指示と望ましい回答で追加学習し、指示に従う能力を高めます。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉
- **プロンプトエンジニアリング**：生成AIへ与える目的、前提、例、制約、出力形式を設計し、結果を評価・改善する活動です。 〈上位概念: 2.1　機械学習の評価と学習／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉

### 2.2　情報と画像

- **位置センサー**：機械部品や物体の位置・変位を測るセンサーの総称です。 〈上位概念: 2.3　制御と測定／[詳説箇所](01_基礎理論.md)／別表記: 特記なし〉

## 3　データ構造、アルゴリズム、言語処理

- **色の3原色（Cyan、Magenta、Yellow）**：印刷インクなど、光を吸収する減法混色のCMYです。 〈上位概念: 4.6　UIと情報メディア／[詳説箇所](03_ハードウェアとコンピュータ構成要素.md)／別表記: Cyan、Magenta、Yellow〉
- **YUVフォーマット**：明るさYと色差U・Vへ分ける画像表現です。YUV411、YUV420、YUV422、YUV444は色差情報をどの程度間引くかが違います。 〈上位概念: 4.6　UIと情報メディア／[詳説箇所](03_ハードウェアとコンピュータ構成要素.md)／別表記: 特記なし〉
- **3次元映像**：左右の目への差、奥行き情報、三次元モデルなどを使い、立体感・空間を表す映像です。 〈上位概念: 4.6　UIと情報メディア／[詳説箇所](03_ハードウェアとコンピュータ構成要素.md)／別表記: 特記なし〉
- **グラフ型のデータモデル**：節と辺で関係を表します。プロパティグラフは節・辺へ属性を持ち、トリプルストアは主語・述語・目的語の三つ組を保存します。 〈上位概念: 4.6　UIと情報メディア／[詳説箇所](03_ハードウェアとコンピュータ構成要素.md)／別表記: 特記なし〉
- **インデックス数**：DBの索引の個数です。多いほど検索候補は増えますが、更新費と容量も増えます。 〈上位概念: 4.6　UIと情報メディア／[詳説箇所](03_ハードウェアとコンピュータ構成要素.md)／別表記: 特記なし〉

## 6　セキュリティの脅威と攻撃

### 6.1　情報漏えいと通信・Web攻撃

- **情報漏えい**：秘密・個人情報などが、許可されない相手へ知られることです。シラバスPDFではふりがなの混入で「情報漏 びゅう えい」のように抽出される場合があります。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](01_基礎理論/20_通信の基礎理論.md#32 暗号化――読める人を制限する)／別表記: 特記なし〉
- **オープンリダイレクトの悪用**：正規サイトの転送機能へ外部URLを与え、利用者を偽サイトへ誘導します。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉
- **中間者攻撃**：通信の間へ入り、盗聴・改ざん・なりすましを行います。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#1 中間者攻撃)／別表記: 特記なし〉
- **リプレイ攻撃**：正しい認証通信などを記録し、後で再送して不正に処理させます。nonceや時刻で再利用を防ぎます。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](08_セキュリティ/06_パスワードと認証情報への攻撃.md#22 リプレイ攻撃)／別表記: 特記なし〉
- **DoS攻撃**：大量要求や脆弱性悪用で、サービスを利用不能・低品質にします。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#9 DoS攻撃)／別表記: 特記なし〉
- **クリプトジャッキング**：他人の端末・サーバ資源を無断で暗号資産の採掘へ使います。 〈上位概念: 6.1　情報漏えいと通信・Web攻撃／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#14 クリプトジャッキング)／別表記: 特記なし〉

### 6.2　標的・検索・未知脆弱性

- **標的型攻撃／APT**：特定組織を狙い、長期間、複数手段で侵入・潜伏・情報窃取を行います。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/05_攻撃者・動機・攻撃の流れ.md#12 標的型攻撃)／別表記: 特記なし〉
- **水飲み場型攻撃**：標的がよく訪れるWebサイトを改ざんし、訪問時に攻撃します。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#15 水飲み場型攻撃)／別表記: 特記なし〉
- **やり取り型攻撃**：無害な連絡を重ねて信用させ、後から不正ファイルやURLを送ります。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#16 やり取り型攻撃)／別表記: 特記なし〉
- **SEOポイズニング**：検索結果の上位へ悪意あるサイトを表示させ、利用者を誘導します。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#17 SEOポイズニング)／別表記: 特記なし〉
- **ゼロデイ攻撃**：修正プログラムが整う前の脆弱性を悪用します。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#19 ゼロデイ攻撃)／別表記: 特記なし〉
- **サービス及びソフトウェアの機能の悪用**：正規機能を攻撃へ転用します。オープンリゾルバをDDoS増幅へ使う例があります。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉
- **バージョンロールバック攻撃**：安全対策済みの新しい版から、既知の弱点がある古い版へ戻させます。 〈上位概念: 6.2　標的・検索・未知脆弱性／[詳説箇所](08_セキュリティ/08_ネットワークとシステムへの攻撃.md#20 バージョンロールバック攻撃)／別表記: 特記なし〉

### 6.3　AIを悪用・攻撃する

- **AIを悪用した攻撃**：詐欺文の巧妙化、なりすまし、マルウェア亜種生成、脆弱性探索の効率化などへAIを使います。 〈上位概念: 6.3　AIを悪用・攻撃する／[詳説箇所](08_セキュリティ/09_AIに関する脅威と攻撃.md#2 二つの方向)／別表記: 特記なし〉
- **バリアント（亜種）**：基本機能を保ちながらコードや特徴を変え、検出を逃れようとするマルウェアの変種です。 〈上位概念: 6.3　AIを悪用・攻撃する／[詳説箇所](08_セキュリティ.md)／別表記: 亜種〉
- **プロンプトインジェクション**：AIへの入力や参照文書へ悪意ある指示を混ぜ、本来の命令を無視させます。 〈上位概念: 6.3　AIを悪用・攻撃する／[詳説箇所](08_セキュリティ/09_AIに関する脅威と攻撃.md#11 プロンプトインジェクション)／別表記: 特記なし〉
- **フットプリンティング**：公開情報などから、組織、ドメイン、システム構成を調べます。 〈上位概念: 6.3　AIを悪用・攻撃する／[詳説箇所](08_セキュリティ/05_攻撃者・動機・攻撃の流れ.md#14 攻撃の準備――フットプリンティング)／別表記: 特記なし〉
- **ポートスキャン**：接続可能なポートを調べ、動作サービスや攻撃可能箇所を探します。 〈上位概念: 6.3　AIを悪用・攻撃する／[詳説箇所](08_セキュリティ/05_攻撃者・動機・攻撃の流れ.md#15 ポートスキャン)／別表記: 特記なし〉

## 7　セキュリティ管理・認証・対策

- **Kerberos方式**：信頼する認証サーバが発行するチケットを使い、ネットワーク上でパスワードを毎回送らず相互認証します。 〈上位概念: 7.1　認証とアクセス管理／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉

- **利用者アクセス権の管理**：need-to-know、つまり知る必要と最小権限に基づき、付与、変更、棚卸し、削除を行います。 〈上位概念: 7.1　認証とアクセス管理／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉

- **特権的アクセス権の管理**：管理者権限を限定し、承認、記録、監視、定期確認を行います。 〈上位概念: 7.1　認証とアクセス管理／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉
- **アクセス権の設定**：主体と資源ごとに、読取り、変更、実行など許す操作を設定します。 〈上位概念: 7.1　認証とアクセス管理／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉

- **クラウドサービスの責任共有モデル**：提供者と利用者が、設備、OS、設定、ID、データなどの安全責任を分担します。サービス形態で境界が変わります。 〈上位概念: 7.2　組織・委託・リスク／[詳説箇所](08_セキュリティ.md)／別表記: 特記なし〉
