# 第7章・第23話　総合演習――通信の仕組みを説明し、計算し、切り分ける80問

この演習は、用語を暗記したかではなく、一つの通信の中で各技術が何をしているかを確かめます。

紙と鉛筆を用意し、先に自分の言葉や計算式を書いてから解答を読んでください。間違えた問題は、解答を覚えるだけでなく、対応する話へ戻って仕組みをたどります。

## 五段階到達度演習

次の一つの題材を、条件を変えながら五段階で解きます。後の段階ほど、前段階の答えを使わなければ解けません。

**共通ケース:** 二拠点VPNでWeb会議と業務通信を共存させ、遅延、損失、DNS障害、無線LAN不正接続へ対処する。

| 段階 | 実際に求める行動 |
|---|---|
| 第1段階 思い出す | 用語を定義し、対象と役割を再現する。 |
| 第2段階 まねる | 与えた値と手順で、途中状態・式・単位を省略せず再現する。 |
| 第3段階 見分ける | 似た概念を、対象・時点・目的・失敗条件の比較軸で区別する。 |
| 第4段階 使う | 同じ題材の条件変更へ知識を適用し、代替案との比較から判断する。 |
| 第5段階 試験水準 | 三つ以上の知識を統合し、前提、計算・設計、失敗時、検証基準まで示す。 |

### 到達度1｜第1段階 思い出す

帯域、スループット、グッドプット、DNS、VPNを一文ずつ定義してください。

### 到達度2｜第2段階 まねる

100Mbit/s回線で、1秒に送った総量が80Mbit、そのうち再送とヘッダが20Mbitだった。スループットとグッドプットを求めてください。

### 到達度3｜第3段階 見分ける

DNS障害とIP到達不能、WPA3と拠点間VPNを区別し、どの区間・対象を守るか答えてください。

### 到達度4｜第4段階 使う

会議通信を優先すると業務ファイル転送が遅くなる。QoSで会議へ最低30Mbit/sを保証する案を、遅延・損失・飢餓の観点で評価してください。

### 到達度5｜第5段階 試験水準

名前解決からTLS通信までの順、QoS、冗長経路、WPA3・端末認証・VPNを含む二拠点構成を設計し、障害注入と測定指標を示してください。

## 五段階到達度演習の解答・採点基準

### 到達度1の解答｜第1段階 思い出す

- **着眼点:** 用語を定義し、対象と役割を再現する。
- **途中と結論:** 帯域は経路の伝送能力、スループットは実際に運ばれた総量/時間、グッドプットは利用者データ量/時間。DNSは名前をIPアドレスへ対応付け、VPNは公衆網上に認証・暗号化された論理的な通信路を作る。
- **採点条件:** 定義に対象と役割があること。単なる略語展開だけは不可。

### 到達度2の解答｜第2段階 まねる

- **着眼点:** 与えた値と手順で、途中状態・式・単位を省略せず再現する。
- **途中と結論:** スループットは80Mbit/s、グッドプットは(80-20)Mbit/s=60Mbit/sである。回線帯域100Mbit/sと実測値を混同しない。
- **採点条件:** 途中状態、式、単位、計算順があり、最終値だけでないこと。

### 到達度3の解答｜第3段階 見分ける

- **着眼点:** 似た概念を、対象・時点・目的・失敗条件の比較軸で区別する。
- **途中と結論:** DNS障害は名前をIPへ変換できないが既知IPへは届く場合がある。IP到達不能は経路自体の問題。WPA3は端末からアクセスポイントまでの無線区間、拠点間VPNは拠点ゲートウェイ間を主に守る。
- **採点条件:** 両概念の比較軸と、誤って交換できない理由があること。
