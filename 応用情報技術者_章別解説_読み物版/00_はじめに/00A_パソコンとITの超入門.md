# 第0部A パソコンとITの超入門――機械を見たことがないところから

画面上のボタンを1回クリックすると、少し待つだけで別のページが現れます。
利用者に見える操作はクリックと表示だけなので、パソコンが一つの仕事として処理したようにも見えます。

けれども、その短い間には、マウス、本体、OS、ブラウザ、ネットワーク、Webサーバ、場合によってはデータベースまでが関わっています。
どれか一つが代わりに全部を処理しているわけではありません。
この1回のクリックを最後まで追えるようになると、IT用語は機械の名前の一覧ではなく、仕事を分担する役割の名前として読めるようになります。

## 1 コンピュータは「指示された処理をする機械」

人に「この紙に書かれた100個の数を全部足してください」と頼む場面を考えます。
人は数を読み、足し算を行い、答えを書きます。
クリックの内側が複雑でも、個々のコンピュータの仕事は大まかに次の3段階へ分けられます。

```text
受け取る → 決められた処理をする → 結果を返す
```

受け取るものを**入力**、行う仕事を**処理**、返す結果を**出力**と呼びます。

電卓なら、数字と「足す」という指示が入力です。
内部で足し算を行うことが処理です。
画面に出る答えが出力です。

```text
入力: 12、+、30
処理: 12と30を足す
出力: 42
```

コンピュータが得意なのは、決められた処理を速く、何度も繰り返すことです。
一方、「いい感じにして」「常識で判断して」のような曖昧な指示は、そのままでは実行できません。
「どのような場合に何をするか」を、機械が扱える形で決める必要があります。

コンピュータは人間のような姿をしている必要はありません。
次のものは、どれもコンピュータの仲間です。

- 机の上で使うパソコン
- 持ち運べるノートパソコン
- スマートフォン
- 自動販売機の中の制御装置
- 自動車のブレーキやエンジンを制御する装置
- 離れた人の画面に文字や画像を送る機械（後で**サーバ**と呼びます）

形と目的は違っても、「入力を受け、決められた処理を行い、結果を出す」という点は共通しています。
ただし、1つの出力が別のコンピュータへの入力になると、この3段階が次々につながります。

## 2 パソコンの外から見える部品

**パソコン**は、個人がさまざまな仕事に使えるコンピュータです。
英語のpersonal computerを短くしてPCとも呼びます。

典型的なパソコンの周りには、次の部品があります。

```text
                 ┌───────────────┐
                 │      画面       │
                 │ 文字や絵を表示  │
                 └───────────────┘
                        │
┌──────────┐    ┌───────────────┐
│ キーボード │    │      本体       │
│文字を入れる│    │ 計算し、記憶する │
└──────────┘    └───────────────┘
                        │
                 ┌──────────┐
                 │  マウス    │
                 │場所を指す  │
                 └──────────┘
```

**画面**は、文字、写真、ボタンなどを表示する部分です。
ディスプレイまたはモニターとも呼びます。

**キーボード**は、文字や数字を入力するための、多数のキーが並んだ部品です。
個々の押す部分がキーです。

**マウス**は、机の上で動かして、画面上の場所を指し示す部品です。
マウスを動かすと、画面上の小さな矢印も動きます。
この矢印を**ポインタ**と呼びます。

本体には、計算する部品、作業中の情報を置く部品、長く情報を保存する部品などがあります。
詳しくは第3章で扱います。

ノートパソコンでは、本体、画面、キーボードが一体になっています。
マウスの代わりに、指を滑らせる平らな部分を使うことがあります。
これをタッチパッドと呼びます。
スマートフォンでは、画面に直接触れて操作します。

### 入力装置と出力装置

人や外部からコンピュータに情報を入れる部品を**入力装置**と呼びます。
キーボード、マウス、マイク、カメラ、温度センサなどが該当します。

コンピュータから人や外部に結果を出す部品を**出力装置**と呼びます。
画面、プリンタ、スピーカーなどが該当します。

1つの部品が両方の役割を持つ場合もあります。
指で操作できる画面は、表示する出力装置であると同時に、触れた場所を受け取る入力装置でもあります。

## 3 電源を入れて操作する

機械を動かすための電気を供給することを、電源を入れるといいます。
本体にある電源ボタンを押すと、パソコンは内部の部品を確認し、利用できる状態を準備します。

準備が終わると、画面に背景、文字、小さな絵などが表示されます。
ここで、利用者の目的に使うソフトウェアを**アプリ**、名前を付けて保存する一まとまりのデータを**ファイル**と呼びます。
どちらも後の節で詳しく説明します。
画面上に表示される小さな絵を**アイコン**と呼びます。
アイコンは、アプリやファイルなどを絵で表したものです。

### マウスの基本操作

マウスには押せる部分があります。
一般に左側のボタンを一度押してすぐ離す操作を**クリック**と呼びます。

- ポインタを対象に合わせる。
- マウスのボタンを一度押す。
- すぐ離す。

これで「この対象を選ぶ」「このボタンを押す」という指示を送れます。

短い間に2回押す操作は**ダブルクリック**です。
画面上の物を開く操作に使われることがあります。
ボタンを押したままマウスを動かし、別の場所で離す操作は**ドラッグ**です。
物を移動したり、範囲を選んだりするときに使います。

同じ操作でも、どこを指しているかによって結果が変わります。
機械は「たぶんこの辺を押したかったのだろう」と常に推測してくれるわけではありません。

### ウィンドウ、ボタン、メニュー

パソコンの画面では、仕事ごとに四角い領域が開きます。
この領域を**ウィンドウ**と呼びます。
窓という意味です。
1枚の画面の上に、複数の仕事の窓を並べられます。

```text
┌──────────── 文章を書くウィンドウ ────────────┐
│ ファイル  編集  表示                         │ ← メニュー
│                                              │
│ ここへ文章を入力します。                      │ ← 入力欄
│                                              │
│                         [ 保存 ]              │ ← ボタン
└──────────────────────────────────────┘
```

**ボタン**は、クリックすると決められた操作を始める画面上の部品です。
実物の押しボタンを画面の中に表したものと考えられます。

**メニュー**は、選べる操作を一覧にしたものです。
飲食店のメニューが注文できる料理を並べるように、画面のメニューは実行できる操作を並べます。

**入力欄**は、文字や数字を入れる場所です。
入力欄をクリックしてキーボードを押すと、文字が表示されます。

## 4 データとプログラム

コンピュータが扱う、文字、数、写真、音などをまとめて**データ**と呼びます。

たとえば学校の名簿では、氏名、学生番号、生年月日がデータです。
写真アプリでは、写真を構成する色の情報や撮影日時がデータです。

コンピュータに行わせる処理の手順を、機械が扱える形で記録したものが**プログラム**です。

料理にたとえると、材料がデータ、調理手順を書いたレシピがプログラム、レシピに従って調理する人や器具がコンピュータに当たります。
ただし、料理人は書かれていないことを常識で補えますが、コンピュータには曖昧さの少ない手順を渡す必要があります。

```text
データ: 80点、75点、90点
プログラム:
  1. 三つの点数を足す
  2. 3で割る
  3. 結果を表示する
出力: 平均81.666…点
```

同じプログラムに別のデータを渡せます。
点数が変わっても、「足して個数で割る」という手順は同じです。

### データの意味は0と1だけでは決まらない

コンピュータの内部では、データは最終的に0と1の並びとして扱われます。
しかし、同じ並びでも「数として読む」「文字として読む」「色として読む」という約束が違えば意味も変わります。

本棚に`42`という札があっても、それが本の冊数なのか、棚番号なのか、気温なのかは札だけでは決まりません。
データには、値と、その値をどう解釈するかという約束が必要です。
この考え方は第1章以降で何度も使います。

## 5 ソフトウェア、アプリ、OS

プログラムや、それを動かすためのデータをまとめて**ソフトウェア**と呼びます。
手で触れられる機械部分である**ハードウェア**と対になる言葉です。

```text
ハードウェア: 本体、画面、キーボード、内部の電子部品
ソフトウェア: 文章作成、写真表示、計算などを行うプログラム群
```

利用者が特定の目的に使うソフトウェアを**アプリケーションソフトウェア**と呼びます。
短く**アプリ**とも呼びます。

- 文章を書くアプリ
- 表を作って計算するアプリ
- 写真を見るアプリ
- インターネット上の文書を結ぶ仕組みである**Web**（World Wide Web）のページを見るブラウザ
- メールを読み書きするアプリ

クリックを受け取るブラウザもアプリの一つです。
ブラウザだけで画面、マウス、保存装置をすべて直接動かせるようにすれば、ほかのアプリも同じ機能を個別に用意しなければなりません。
複数のアプリに共通する仕事を引き受ける基本ソフトウェアが**OS**です。
OSはOperating Systemの略で、日本語ではオペレーティングシステムといいます。

OSは、たとえば次の仕事をします。

- どのアプリに計算する時間を渡すか決める。
- アプリが使う記憶場所を分ける。
- キーボードからの入力をアプリに渡す。
- 画面に表示する仕事を管理する。
- ファイルを保存し、後で探せるようにする。
- 利用者ごとに、許される操作を分ける。

```text
利用者
  ↓ 操作
アプリ
  ↓ 共通の仕事を依頼
OS
  ↓ 機械を制御
ハードウェア
```

アプリとOSは同じものではありません。
文章作成アプリを閉じてもOSは動き続けます。
OSがなければ、通常のアプリは画面や保存装置を共通の方法で使えません。

## 6 作業中の記憶と、長く残す保存

机で勉強するとき、今使っている本や紙を机の上に置きます。
机はすぐ手が届きますが、置ける量に限りがあります。
使い終わった資料は本棚に戻します。
本棚は多く置けますが、取りに行く時間が掛かります。

コンピュータにも似た役割の違いがあります。

**メモリ**は、実行中のプログラムと、今使っているデータを一時的に置く場所です。
主記憶とも呼びます。
計算と指示を進める中心部品である**CPU**（Central Processing Unit、中央処理装置）から素早く使えますが、一般的なメモリの内容は電源を切ると失われます。

**保存装置**は、ファイルを長く残す場所です。
**SSD**（Solid State Drive、半導体に保存する装置）や**HDD**（Hard Disk Drive、磁気円盤に保存する装置。
ハードディスク）などがあります。
保存装置は一般にはメモリより遅い一方、大量のデータを置け、電源を切っても内容が残ります。

```text
              メモリ                  保存装置
役割          今使うものを置く        後でも使うものを残す
速さ          速い                    比較的遅い
容量          比較的小さい            比較的大きい
電源を切る    通常は内容が消える      内容が残る
たとえ        作業机                  本棚・倉庫
```

「保存ボタンを押さずに電源を切ったら文章が消えた」ということがあるのは、変更内容がメモリにしかなく、保存装置に書かれていなかったためです。

机と本棚のたとえは役割を理解する助けになりますが、実際にはOSがデータを自動的に一時保存したり、保存装置の一部をメモリの代わりに使ったりします。
詳しい仕組みは第3章と第5章で扱います。

## 7 ファイルとフォルダ

保存装置に置かれた、ひとまとまりのデータを**ファイル**と呼びます。

- 1つの文章を保存したファイル
- 1枚の写真を保存したファイル
- 一曲分の音を保存したファイル
- 1つのプログラムを保存したファイル

ファイルには、見分けるための**ファイル名**を付けます。
たとえば`旅行の予定.txt`や`写真001.jpg`です。
末尾の`.txt`や`.jpg`は、どのような種類のデータかを表す手掛かりです。
この末尾部分を**拡張子**と呼びます。

大量の紙を1つの引出しに乱雑に入れると探しにくくなります。
そこで、ファイルを分類して入れる入れ物を使います。
これが**フォルダ**です。
ディレクトリとも呼びます。

フォルダの中に、さらにフォルダを入れられます。

```text
文書
├─ 学校
│  ├─ 時間割.txt
│  └─ 課題.txt
└─ 旅行
   ├─ 予定.txt
   └─ 持ち物.txt
```

このように親子関係で枝分かれする形を階層構造と呼びます。

ファイルを使う代表的な操作は次のとおりです。

- **作成する**――新しいファイルを作る。
- **開く**――内容を使える状態にする。
- **保存する**――変更内容を保存装置に残す。
- **コピーする**――同じ内容を持つ別のファイルを作る。
- **移動する**――置かれているフォルダを変える。
- **名前を変更する**――内容を変えず、呼び名を変える。
- **削除する**――不要として取り除く。

コピーと移動は違います。
コピーでは元と複製の2つが残ります。
移動では同じファイルの置き場所が変わります。

## 8 通信とネットワーク

1台のパソコンの中だけでなく、別のコンピュータに情報を送りたいことがあります。
2台以上の機器をつなぎ、情報をやり取りできるようにしたものが**ネットワーク**です。

近くの機器は、電線や光ファイバーでつなげます。
線を使わず、電波でつなぐこともできます。
線や電波でつなぐだけでは、情報を正しく渡せません。
送る側と受け取る側が、情報の表し方と送り方の約束を共有する必要があります。

世界中の多数のネットワークを相互につないだ仕組みが**インターネット**です。
インターネットは、1台の巨大な機械ではありません。
多くの組織や家庭のネットワークが、共通の約束で情報を受け渡す全体です。

```text
家庭のネットワーク ─┐
学校のネットワーク ─┼─ インターネット ─ 企業のネットワーク
会社のネットワーク ─┘
```

インターネットとWebは同じものではありません。
インターネットは通信の土台です。
その土台を使う仕組みの1つがWebです。
メールや音声通話もインターネットを利用できますが、Webページそのものではありません。

## 9 ブラウザ、Webページ、Webサイト

インターネット上の文書や画像を、互いに参照できる形で公開し、閲覧する仕組みを**Web**と呼びます。
World Wide Webを短くした名前です。

Web上の1枚の文書が**Webページ**です。
関連するWebページをひとまとまりとして公開したものが**Webサイト**です。
本にたとえると、1ページがWebページ、本全体がWebサイトに近い関係です。

Webページを受け取り、文字、画像、ボタンなどとして画面に表示するアプリが**Webブラウザ**です。
短くブラウザと呼びます。

ブラウザ上部などに、見たい場所を表す文字列を入力する欄があります。
Web上の場所を表す文字列を**URL**と呼びます。

```text
https://example.com/news/index.html
```

今は、この文字列全体が「どの方法で、どの相手の、どの内容を取りに行くか」を示す住所のようなものだと考えてください。
各部分は第7章で1つずつ説明します。

ブラウザにURLを入力して実行すると、ブラウザはネットワークの向こう側に「このページを送ってください」と要求します。
相手からページのデータが返ると、ブラウザが画面に組み立てて表示します。

## 10 サーバとクライアント

図書館で、利用者が本を頼み、職員が本を探して渡す場面を考えます。
頼む側と、求めに応じて提供する側がいます。

ネットワーク上でサービスを利用する側を**クライアント**、要求を受けてサービスやデータを提供する側を**サーバ**と呼びます。

Webを見る場面では、ブラウザがクライアントです。
Webページを保存し、要求に応じて送り返すコンピュータやソフトウェアがWebサーバです。

```text
ブラウザ                         Webサーバ
  │ 「ページをください」             │
  ├────────────────────────→│
  │                                 │ 保存場所から探す
  │     「ページのデータです」        │
  │←────────────────────────┤
  │ 画面へ表示                       │
```

矢印は情報が進む向きです。
上の図では、最初の矢印が要求、次の矢印が応答です。

「サーバ」と聞くと、特別な形をした大きな機械を想像しやすいかもしれません。
しかし、1台の機械が常にクライアント専用またはサーバ専用とは限りません。
ある通信では要求する側であり、別の通信では提供する側になることがあります。
また、「サーバ」という言葉は、役割を持つソフトウェアを指す場合と、そのソフトウェアを動かす機械を指す場合があります。
前後の文脈で見分けます。

## 11 データベース

学校の学生情報を紙で管理すると、人数が増えるほど探すのが大変です。
複数の職員が同時に書き換えると、どれが最新か分からなくなることもあります。

目的に沿って整理し、複数の処理から共同利用できるようにしたデータの集まりを**データベース**と呼びます。

データベースは、単にデータを入れた大きな箱ではありません。
一般には、次のような仕事も必要です。

- 条件に合うデータを探す。
- 新しいデータを加える。
- 間違った値が入らないよう制限する。
- 複数人の同時更新で矛盾しないようにする。
- 見てよい人と、変更してよい人を分ける。
- 故障後に正しい状態に戻す。

これらを管理するソフトウェアをDBMSと呼びます。
Database Management Systemの略で、データベース管理システムという意味です。
詳しくは第6章で学びます。

## 12 一回のクリックを全体で追う

冒頭で見た1回のクリックへ戻ります。
ブラウザで学校のWebサイトを開き、「今日のお知らせ」というボタンをクリックする場面です。

1. 利用者がマウスを動かし、ポインタをボタンに合わせる。
2. クリックが入力装置からパソコンに伝わる。
3. OSが、クリックされた場所の情報をブラウザに渡す。
4. ブラウザ内のプログラムが、「お知らせページを要求する」と判断する。
5. ブラウザがネットワークを通じてWebサーバに要求を送る。
6. Webサーバが要求を受け取る。
7. 必要なら、Webサーバがデータベースに今日のお知らせを問い合わせる。
8. データベースが該当するデータを返す。
9. Webサーバがページのデータをブラウザに返す。
10. ブラウザが受け取ったデータを文字や画像として組み立てる。
11. OSが画面を制御し、利用者にお知らせを表示する。

```text
利用者
  ↓ クリック
入力装置
  ↓
OS → ブラウザ → ネットワーク → Webサーバ → データベース
  ↑                  ← 応答       ← データ ──┘
  └──── 画面へ表示 ─────────────────────┘
```

利用者から見えたのは、最初のクリックと最後の表示だけでした。
その間では、前の処理が出した情報を次の処理が受け取り、11の段階がつながっています。

実際には、相手の場所を調べる、データを小分けにする、届かなければ送り直す、通信相手が本物か確かめる、といった処理もあります。
第3章から第8章では、この1回の操作の内側を順に開いていきます。

## 13 初めて出た言葉の整理

| 言葉 | この時点での意味 |
|---|---|
| 入力 | コンピュータが受け取る情報や指示 |
| 処理 | 入力に対して行う仕事 |
| 出力 | 処理後に返す結果 |
| データ | コンピュータが扱う数、文字、画像など |
| プログラム | コンピュータに行わせる処理の手順 |
| ハードウェア | 手で触れられる機械部分 |
| ソフトウェア | プログラムと、それを動かすためのデータ |
| アプリ | 利用者が特定目的に使うソフトウェア |
| OS | 複数のアプリに共通する基本的な管理を行うソフトウェア |
| メモリ | 実行中に使う情報を一時的に置く場所 |
| 保存装置 | 情報を電源断後も残す場所 |
| ファイル | 保存された、ひとまとまりのデータ |
| フォルダ | ファイルや別のフォルダを整理する入れ物 |
| ネットワーク | 複数の機器をつないで通信できるようにしたもの |
| インターネット | 多数のネットワークを相互接続した仕組み |
| Web | インターネット上の文書などを参照・閲覧する仕組み |
| ブラウザ | Webページを受け取り表示するアプリ |
| クライアント | サービスを要求し利用する側 |
| サーバ | 要求を受け、サービスやデータを提供する側 |
| データベース | 目的に沿って整理し共同利用するデータの集まり |

表の用語を個別に覚えるだけでは、クリックのどの段階を指すかは分かりません。
入力から表示までの流れへ戻し、それぞれが受け取るもの、行う処理、返すものを確かめると、近い用語も役割で区別できます。
