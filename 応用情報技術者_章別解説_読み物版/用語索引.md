# 全巻用語索引――知らない言葉から説明へ戻る

## この索引の使い方

「認証」と「認可」は、一字しか違わず、どちらもアクセス制御の説明に現れます。
索引を引けば、認証は「誰かを確かめる」、認可は「何を許すか決める」とすぐに区別できます。
ただし、その一行を読めたことと、システムのどの時点で必要かを判断できることは同じではありません。

この索引は、一言だけを暗記するための一覧ではありません。
分からない語の最初の意味をつかみ、必要性、仕組み、例、使える条件まで本文へ確かめに戻るための案内です。

1. ページ内検索で用語を探す
2. 短い説明を読む
3. その用語が属する章を開く
4. 必要性、仕組み、例、使える条件まで確認する

英字の略語は、英字の項と日本語の項の両方に現れることがあります。
法律や規格は改正されるため、実務では最新の公式資料も確認してください。

## 第1章　基礎理論の用語

詳しくは[第1章の読み順](01_基礎理論/00_基礎理論.md)から進みます。

- **ビット**：0または1のどちらか一方を表せる情報の最小単位。
  （[詳説](01_基礎理論/01_数と二進数.md#2 一個の箱が一ビット)）
- **バイト**：通常8ビットを一まとまりにした単位。
  （[詳説](01_基礎理論/01_数と二進数.md#3 八ビットを一バイトとして扱う)）
- **二進数**：0と1だけを使い、桁が1つ左に移ると重みが2倍になる数の表し方。
  （[詳説](00_はじめに/00B_数学の超入門.md#2 桁と位)）
- **十六進数**：0から9とAからFを使い、桁が1つ左に移ると重みが16倍になる表し方。
  （[詳説](01_基礎理論/01_数と二進数.md#10 十六進数は長い二進数を短く読む道具)）
- **補数**：引き算や負の数を、足し算として扱いやすくする表現。
  （[詳説](01_基礎理論/02_整数と負の数.md#同じビット列が255にもマイナス1にもなる)）
- **固定小数点**：小数点の位置をあらかじめ固定して数を表す方式。
  （[詳説](01_基礎理論/03_小数と浮動小数点.md#3 固定小数点――小数点の場所を皆で決める)）
- **浮動小数点**：符号、仮数、指数を使い、小さい数から大きい数まで限られた桁で表す方式。
  （[詳説](00_はじめに/00B_数学の超入門.md#終わらない小数)）
- **丸め誤差**：表せる桁数に限りがあるため、近い値に丸めることで生じる差。
  （[詳説](01_基礎理論/03_小数と浮動小数点.md#16 浮動小数点で起きる代表的な誤差)）
- **桁落ち**：ほぼ等しい2つの数を引き、有効な桁が大きく失われること。
  （[詳説](01_基礎理論/03_小数と浮動小数点.md#情報落ち)）
- **情報落ち**：大きさが極端に違う数を足し、小さい側の情報が結果に反映されなくなること。
  （[詳説](01_基礎理論/03_小数と浮動小数点.md#丸め誤差)）
- **集合**：条件を満たすものを、重複なく集めたもの。
  （[詳説](01_基礎理論/04_集合と論理.md#1 カードを条件ごとに仕分ける)）
- **論理積（AND）**：2つの条件が両方真のときだけ真になる演算。
  （[詳説](01_基礎理論/04_集合と論理.md#9 論理積AND――両方が真)）
- **論理和（OR）**：2つの条件の少なくとも一方が真なら真になる演算。
  （[詳説](01_基礎理論/04_集合と論理.md#10 論理和OR――少なくとも片方が真)）
- **否定（NOT）**：真と偽を反対にする演算。
  （[詳説](01_基礎理論/04_集合と論理.md#11 否定NOT――真偽を反対にする)）
- **排他的論理和（XOR）**：2つの条件の一方だけが真のとき真になる演算。
  （[詳説](01_基礎理論/04_集合と論理.md#12 排他的論理和XOR)）
- **真理値表**：入力となる真偽の全組合せと、演算結果を並べた表。
  （[詳説](01_基礎理論/04_集合と論理.md#9 論理積AND――両方が真)）
- **確率**：不確実な出来事が起こる程度を0から1で表したもの。
  （[詳説](01_基礎理論/08_確率と統計.md#1 確率は「起こりやすさ」を0から1で表す)）
- **期待値**：各結果にその確率を掛けて足した、繰返し時の平均的な値。
  （[詳説](01_基礎理論/08_確率と統計.md#10 期待値――長く繰り返したときの平均)）
- **平均**：複数の値の合計を個数で割った、中心の1つの表し方。
  （[詳説](00_はじめに/00A_パソコンとITの超入門.md#4 データとプログラム)）
- **中央値**：値を順に並べたとき中央に来る値。
  （[詳説](00_はじめに/00B_数学の超入門.md#18 平均)）
- **分散**：各値が平均からどれほど離れているかを、二乗して平均したばらつきの指標。
  （[詳説](01_基礎理論/08_確率と統計.md#12 分散と標準偏差――平均からどれだけ散らばるか)）
- **標準偏差**：分散の平方根。
  元データと同じ単位でばらつきを表す。
  （[詳説](01_基礎理論/08_確率と統計.md#12 分散と標準偏差――平均からどれだけ散らばるか)）
- **相関**：2つの値が一緒に増減する傾向。
  相関だけでは因果関係を証明できない。
  （[詳説](01_基礎理論/08_確率と統計.md#20 相関と因果)）
- **行列**：数を縦横に並べ、複数の関係や計算をまとめて扱うもの。
  （[詳説](01_基礎理論/09_数値計算と最適化.md#14 行列――数を長方形に並べる)）
- **ベクトル**：大きさと向き、または複数の成分を1列にまとめたもの。
  （[詳説](01_基礎理論/09_数値計算と最適化.md#13 ベクトル――複数の数を一組として扱う)）
- **情報量**：起こりにくい出来事を知ったときほど大きくなる、情報の驚きの量。
  （[詳説](01_基礎理論/05_情報量と符号.md#3 珍しい知らせほど情報量が大きい)）
- **エントロピー**：どの結果になるかの不確かさを平均情報量で表したもの。
  （[詳説](01_基礎理論/05_情報量と符号.md#5 平均すると、情報源全体の不確かさになる)）
- **符号化**：情報を、保存・通信に適した記号列に変換すること。
  （[詳説](01_基礎理論/05_情報量と符号.md#7 符号化――対象をビット列へ対応させる)）
- **誤り検出**：通信・保存中にデータが変わったことを見つけること。
  （[詳説](07_ネットワーク/06_伝送制御と誤り制御.md#14 誤り検出と訂正)）
- **誤り訂正**：誤りの位置や内容を推定し、元のデータに直すこと。
  （[詳説](07_ネットワーク/06_伝送制御と誤り制御.md#14 誤り検出と訂正)）
- **オートマトン**：状態と入力による状態変化で、処理の振る舞いを表すモデル。
  （[詳説](01_基礎理論/06_状態と形式言語.md#5 有限オートマトン)）
- **形式言語**：決められた規則で作れる文字列の集合。
  （[詳説](01_基礎理論/06_状態と形式言語.md#8 形式言語)）
- **標本化**：連続する音や信号を、一定時間ごとに測って数値にすること。
  （[詳説](01_基礎理論/13_信号処理.md#2 標本化――時間を区切って測る)）
- **量子化**：測った値を、有限個の段階のいずれかに丸めること。
  （[詳説](01_基礎理論/13_信号処理.md#3 量子化――測定値を有限段階へ丸める)）
- **フィードバック制御**：出力を測り、目標との差を減らすよう入力を調整する制御。
  （[詳説](01_基礎理論/10_計測と制御.md#5 フィードバック制御)）

  （[詳説](06_データベース/03_関係モデルとキー.md#9 主キーと代替キー)）
- **外部キー**：別の表の主キーを参照し、表どうしの関係を表す列。
  （[詳説](06_データベース/03_関係モデルとキー.md#12 外部キー)）
- **正規化**：同じ事実の重複と更新時の矛盾を減らすよう、表を分けること。

- **E-R図**：実体と、その間の関係を図で表す設計方法。

- **SQL**：関係データベースに、検索、追加、変更、削除などを依頼する言語。
  （[詳説](06_データベース/09_SQLと表の定義.md#第6章 第9話 SQLと表の定義)）
- **SELECT**：SQLで、条件に合う行や列を取り出す命令。
  （[詳説](00_はじめに/00C_図・式・コードの読み方.md#7 SQLはデータベースへの依頼文)）
- **JOIN**：共通する値を使い、複数表の行を結び付ける操作。
  （[詳説](06_データベース/11_結合と副問合せ.md#2 内部結合)）
- **インデックス**：値から行の場所を速く探すための索引。
  （[詳説](05_ソフトウェア/12_ファイル編成とバックアップ.md#10 インデックス)）
- **トランザクション**：途中状態を外に見せず、一まとまりとして成功・失敗させる処理単位。

- **ACID特性**：原子性、一貫性、分離性、耐久性というトランザクションの基本性質。
  （[詳説](06_データベース/14_トランザクションとACID.md#4 ACID特性)）
- **コミット**：トランザクションの変更を確定すること。
  （[詳説](09_システム開発技術/33_開発環境管理.md#26 コミット)）
- **ロールバック**：トランザクションの変更を取り消し、前の状態に戻すこと。
  （[詳説](09_システム開発技術/34_構成管理・変更管理・リリース管理.md#53 ロールバックとロールフォワード)）
- **ロック**：同時処理が同じデータを壊さないよう、利用を一時制限すること。
  （[詳説](06_データベース/15_同時実行制御とMVCC.md#6 ロック)）
- **排他制御**：同時更新の順序を管理し、矛盾を防ぐこと。
  （[詳説](05_ソフトウェア/05_同期・排他・デッドロック.md#3 排他制御)）
- **ログ**：変更内容や処理履歴を順に記録したもの。
  （[詳説](02_アルゴリズムとプログラミング/17_コーディング規約・モジュール・品質.md#26 ログ)）
- **バックアップ**：障害や誤操作に備え、別に保存したデータの写し。
  （[詳説](05_ソフトウェア/12_ファイル編成とバックアップ.md#14 バックアップの目的)）
- **レプリケーション**：データの複製を別の場所に保ち、可用性や読出し能力を高めること。

- **NoSQL**：表形式だけに限定せず、文書、キー値、グラフなどを扱うデータベース群。

## 第7章　ネットワークの用語

詳しくは[第7章の読み順](07_ネットワーク/00_ネットワーク.md)から進みます。

- **プロトコル**：通信する機器どうしが守る、データ形式と手順の約束。
  （[詳説](07_ネットワーク/01_ネットワークとは何か.md#5 プロトコル)）
- **OSI基本参照モデル**：通信機能を7つの層に分けて理解するモデル。
  （[詳説](07_ネットワーク/05_OSI基本参照モデル.md#2 OSI基本参照モデル)）
- **TCP/IP**：インターネットで使う通信プロトコル群。
  （[詳説](07_ネットワーク/09_IPv4とサブネット.md#1 IPの役割)）
- **フレーム**：主に同じネットワーク内で運ぶデータのまとまり。
  （[詳説](05_ソフトウェア/17_Web・人間中心設計・アクセシビリティ.md#4 フレーム)）
- **パケット**：ネットワークを越えて運ぶデータのまとまり。
  （[詳説](01_基礎理論/18_待ち行列とシミュレーション.md#2.1 客)）
- **セグメント**：TCPがアプリのデータを分けた単位。
  （[詳説](05_ソフトウェア/06_実記憶管理.md#15 セグメント方式への入口)）
- **MACアドレス**：同じLAN内で機器のインタフェースを識別する番号。
  （[詳説](07_ネットワーク/07_Ethernet・スイッチ・VLAN.md#1 MACアドレス)）
- **IPアドレス**：複数ネットワークを越えて通信相手の場所を識別する番号。
  （[詳説](05_ソフトウェア/08_入出力・データ・運用管理.md#15 ネットワーク制御)）
- **IPv4**：32ビットのIPアドレスを使う方式。
  （[詳説](07_ネットワーク/09_IPv4とサブネット.md#2 IPv4アドレス)）
- **IPv6**：128ビットのIPアドレスを使う方式。
  （[詳説](07_ネットワーク/10_ARP・DHCP・IPv6・NAT.md#16 IPv6)）
- **サブネットマスク**：IPv4アドレスのどこまでがネットワーク部かを示す値。
  （[詳説](07_ネットワーク/09_IPv4とサブネット.md#5 サブネットマスク)）
- **CIDR**：アドレスのネットワーク部の長さを `/24` などで表し、柔軟に分割する方式。
  （[詳説](07_ネットワーク/09_IPv4とサブネット.md#6 CIDR表記)）
- **ルータ**：宛先IPアドレスを見て、別のネットワークにパケットを送る装置。
  （[詳説](07_ネットワーク/11_ルーティング.md#1 ルータ)）
- **スイッチ**：主にMACアドレスを見て、LAN内の適切なポートにフレームを送る装置。
  （[詳説](01_基礎理論/01_数と二進数.md#1 たくさんの状態より、二つの状態を確実に見分ける)）
- **ルーティング**：宛先ネットワークまでの経路を選ぶこと。
  （[詳説](02_アルゴリズムとプログラミング/19_Webプログラミング.md#28 クライアント側ルーティング)）
- **デフォルトゲートウェイ**：自分のネットワーク外に送るとき、最初に渡すルータ。
  （[詳説](07_ネットワーク/11_ルーティング.md#2 デフォルトゲートウェイ)）
- **ARP**：同じIPv4ネットワーク内で、IPアドレスに対応するMACアドレスを調べる仕組み。
  （[詳説](07_ネットワーク/10_ARP・DHCP・IPv6・NAT.md#1 ARP)）
- **TCP**：順序、再送、流量を管理し、信頼性のあるバイト列通信を提供するプロトコル。
  （[詳説](07_ネットワーク/12_TCPとUDP.md#5 TCP)）
- **UDP**：到着保証を簡略化し、小さな負担でデータグラムを送るプロトコル。
  （[詳説](07_ネットワーク/12_TCPとUDP.md#18 UDP)）
- **ポート番号**：1台の機器内で、どのアプリやサービスに渡すかを識別する番号。
  （[詳説](07_ネットワーク/12_TCPとUDP.md#1 ポート番号)）
- **DNS**：ドメイン名をIPアドレスなどに対応付ける仕組み。
  （[詳説](07_ネットワーク/13_アプリケーション層プロトコル.md#1 DNS)）
- **DHCP**：IPアドレスやDNS情報を端末に自動配布する仕組み。
  （[詳説](07_ネットワーク/10_ARP・DHCP・IPv6・NAT.md#5 DHCP)）
- **NAT**：IPアドレスを別のIPアドレスに変換する仕組み。
  （[詳説](07_ネットワーク/10_ARP・DHCP・IPv6・NAT.md#12 NAT)）
- **HTTP**：Webの要求と応答を交換するプロトコル。
  （[詳説](02_アルゴリズムとプログラミング/19_Webプログラミング.md#5 HTTP)）
- **HTTPS**：HTTPをTLSで保護し、暗号化・相手確認・改ざん検知を行う通信。
  （[詳説](07_ネットワーク/13_アプリケーション層プロトコル.md#12 HTTPS)）
- **LAN**：建物や敷地など比較的狭い範囲のネットワーク。
  （[詳説](07_ネットワーク/01_ネットワークとは何か.md#9 LAN)）
- **WAN**：離れた拠点など広い範囲を結ぶネットワーク。
  （[詳説](07_ネットワーク/01_ネットワークとは何か.md#10 WAN)）
- **無線LAN**：電波を使ってLANに接続する方式。
  （[詳説](01_基礎理論/13_信号処理.md#19 通信で波を使う)）
- **帯域幅**：単位時間に運べる情報量の上限的な大きさ。
  （[詳説](01_基礎理論/20_通信の基礎理論.md#5 周波数と帯域幅)）
- **遅延**：送信してから到着・応答するまでにかかる時間。
  （[詳説](07_ネットワーク/04_トラフィックと品質.md#5 遅延)）
- **ジッタ**：パケットごとの遅延時間のばらつき。
  （[詳説](07_ネットワーク/04_トラフィックと品質.md#9 ジッタ)）
- **SNMP**：ネットワーク機器の状態取得や設定に使う管理プロトコル。
  （[詳説](07_ネットワーク/13_アプリケーション層プロトコル.md#20 SNMP)）
- **VPN**：公衆ネットワーク上に、暗号などで保護した論理的な専用経路を作る仕組み。
  （[詳説](07_ネットワーク/17_仮想ネットワーク.md#6 VPN)）

## 第8章　セキュリティの用語

詳しくは[第8章の読み順](08_セキュリティ/00_セキュリティ.md)から進みます。

- **情報セキュリティ**：情報とシステムの機密性、完全性、可用性などを守ること。

- **リスクアセスメント**：資産、脅威、脆弱性、影響を調べ、リスクを評価すること。
  （[詳説](08_セキュリティ/16_リスクアセスメントとリスク対応.md#3 リスクアセスメント)）
- **リスク回避**：危険を生む活動自体をやめること。
  （[詳説](08_セキュリティ/16_リスクアセスメントとリスク対応.md#21 リスク回避)）
- **リスク低減**：対策により起こりやすさや影響を小さくすること。
  （[詳説](08_セキュリティ/16_リスクアセスメントとリスク対応.md#22 リスク低減とリスクコントロール)）
- **リスク移転**：保険や契約などで金銭的影響の一部を他者に移すこと。

- **リスク受容**：評価した上で、対策せず受け入れること。
  （[詳説](08_セキュリティ/16_リスクアセスメントとリスク対応.md#20 リスク対応の選択肢)）
- **認証**：利用者や機器が名乗る本人・本物かを確かめること。

- **認可**：認証後、その主体にどの操作を許すか決めること。

- **多要素認証**：知識、所持、生体など異なる種類の要素を組み合わせて認証すること。

- **アクセス制御**：誰が、どの資源に、何をできるかを制限する仕組み。

- **最小権限**：仕事に必要な最小限の権限だけを与える原則。

- **暗号化**：鍵を使い、読めるデータを第三者が理解しにくい形に変えること。

- **公開鍵暗号**：公開鍵と秘密鍵の対を使う方式。
  （[詳説](08_セキュリティ/11_公開鍵暗号・鍵共有・鍵管理.md#第8章 第11話 公開鍵暗号と鍵共有と鍵管理)）
- **ハッシュ関数**：任意長のデータから固定長の値を計算し、元に戻しにくくする関数。
  （[詳説](08_セキュリティ/12_ハッシュ・MAC・デジタル署名.md#1 ハッシュ関数)）
- **デジタル署名**：秘密鍵で署名し、公開鍵で作成者と改ざんの有無を検証する仕組み。
  （[詳説](08_セキュリティ/12_ハッシュ・MAC・デジタル署名.md#14 デジタル署名)）
- **電子証明書**：公開鍵と所有者の情報を、認証局の署名で結び付けた電子文書。

  （[詳説](08_セキュリティ/15_PKIとデジタル証明書.md#1 PKI)）
- **マルウェア**：不正・有害な目的で動くソフトウェアの総称。
  （[詳説](08_セキュリティ/04_マルウェア.md#第8章 第4話 マルウェア)）
- **ウイルス**：他のファイルなどに自分を付け、条件により広がるマルウェア。
  （[詳説](08_セキュリティ/04_マルウェア.md#3 コンピュータウイルス)）
- **ワーム**：ネットワークなどを通じ、自力で複製・拡散するマルウェア。
  （[詳説](08_セキュリティ/04_マルウェア.md#5 ワーム)）
- **ランサムウェア**：データを暗号化・窃取し、身代金を要求するマルウェア。
  （[詳説](08_セキュリティ/04_マルウェア.md#9 ランサムウェア)）
- **フィッシング**：偽の連絡やサイトで、認証情報や金銭をだまし取る攻撃。
  （[詳説](08_セキュリティ/03_脅威と人が関わる不正.md#12 フィッシング)）
- **SQLインジェクション**：入力をSQLの一部として誤解釈させ、不正なDB操作を行う攻撃。
  （[詳説](08_セキュリティ/07_Webアプリケーションへの攻撃.md#5 SQLインジェクション)）
- **XSS**：Webページに悪意あるスクリプトを混入し、閲覧者のブラウザで実行させる攻撃。
  （[詳説](02_アルゴリズムとプログラミング/19_Webプログラミング.md#38 XSS)）
- **CSRF**：ログイン中の利用者に、意図しない要求を送らせる攻撃。
  （[詳説](02_アルゴリズムとプログラミング/19_Webプログラミング.md#40 CSRF)）
- **DoS／DDoS**：大量要求などで資源を使い切らせ、サービスを利用しにくくする攻撃。
  （[詳説](08_セキュリティ/04_マルウェア.md#1 マルウェアの目的)）
- **ファイアウォール**：通信元、宛先、ポートなどの規則で通信を許可・遮断する仕組み。
  （[詳説](07_ネットワーク/10_ARP・DHCP・IPv6・NAT.md#23 ファイアウォール)）
- **IDS**：不審な通信や挙動を検知して知らせる仕組み。
  （[詳説](08_セキュリティ/23_ネットワークセキュリティ製品と境界防御.md#13 IDS)）
- **IPS**：不審な通信や挙動を検知し、遮断も行う仕組み。
  （[詳説](08_セキュリティ/23_ネットワークセキュリティ製品と境界防御.md#14 IPS)）
- **WAF**：WebアプリへのHTTP通信を検査し、代表的な攻撃を防ぐ仕組み。
  （[詳説](08_セキュリティ/23_ネットワークセキュリティ製品と境界防御.md#11 WAF)）
- **脆弱性診断**：既知の弱点や設定不備を調べること。
  （[詳説](08_セキュリティ/20_セキュリティ技術評価.md#12 脆弱性診断)）
- **ペネトレーションテスト**：定めた範囲で実際の攻撃手法を試し、侵入可能性と影響を確認すること。

## 混同しやすい語の最短比較

似た語を別々に覚えると、問題文の中で交換してよいように見えることがあります。
次の表では、二つを分ける最短の軸だけを先に確認し、判断に迷った語は詳説へ戻ります。

| 語 | 違い |
|---|---|
| ビット／バイト | ビットは0か1、通常8ビットで1バイト |
| メモリ／保存装置 | メモリは主に作業中、SSDやHDDは長期保存 |
| Web／インターネット | インターネットは通信基盤、Webはその上の情報閲覧の仕組み |
| サーバ／クライアント | サーバは提供側、クライアントは要求・利用側。役割なので同じ機器が両方になり得る |
| 暗号化／ハッシュ | 暗号化は鍵で復号する前提、ハッシュは原則として元に戻さない要約 |
| 認証／認可 | 認証は誰かを確かめ、認可は何を許すかを決める |
| バックアップ／冗長化 | バックアップは過去データに戻す写し、冗長化は故障時も動かす予備 |
| 要求／要件 | 要求は必要や願い、要件は確認可能な条件に具体化したもの |
| インシデント管理／問題管理 | 前者は早い復旧、後者は原因と再発防止 |
| BPR／BPM | BPRは抜本的再設計、BPMは継続的な可視化・実行・改善 |
| ROI／NPV | ROIは割合、NPVは時間価値を反映した金額 |
| 貸借対照表／損益計算書 | 前者は1時点の財産状態、後者は一定期間の利益 |
| 請負／準委任 | 請負は完成責任、準委任は適切な事務処理が中心 |
| 標準化機関／認証機関 | 前者は規格を作り、後者は規格への適合を審査する |

それ以外の低頻度語・別表記は、[全巻シラバス用語補遺](14_シラバス用語補遺.md)を確認してください。
それでも見つからない語は教材フォルダ全体を検索します。
ある語が説明なしで初めて現れている場合は、読者が推測すべきものではなく、本文側で補うべき説明漏れです。

「認証」と「認可」のように語が見つかった場合も、短い定義で検索を終えないでください。
誰を確かめ、何を許し、誤ると何が起きるのかまで本文で追えたとき、索引の一行が問題を解く知識になります。
