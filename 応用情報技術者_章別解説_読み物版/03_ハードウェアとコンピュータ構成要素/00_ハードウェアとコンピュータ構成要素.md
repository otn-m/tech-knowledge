# 第3章　ハードウェアとコンピュータ構成要素――箱の中で何が動いているのか

CPUを速いものへ交換すれば、コンピュータ全体も同じ割合で速くなるように思えます。
ところが、必要なデータが届かなければCPUは待ち、装置への転送が詰まれば処理は先へ進みません。
並列にできない部分が残れば、CPUを増やした効果にも上限があります。

速さを決めるのは、一つの部品の性能ではありません。
命令とデータが、どこに置かれ、どの通り道を進み、どこで待つかです。

この章では、一つの命令が取り出され、データを読み、現実の装置へ結果を返すまでを追います。
部品名を覚えるだけでは見えない、箱の中の待ち合わせが見えてきます。

## この章で身に付けること

読み終えると、次を自分の言葉で説明し、紙の上で小さな計算ができることを目標にします。

- コンピュータの五大装置と、データ・制御の流れを説明する。
- CPUの命令取出しから実行までを、レジスタの変化とともに追う。
- アドレス指定を使って、実際に参照する番地を計算する。
- 割込み、マイクロプログラム、パイプラインの目的を説明する。
- クロック、CPI、MIPS、FLOPSから処理時間を計算する。
- 並列処理の速さと限界を、アムダールの法則で計算する。
- RAM、ROM、キャッシュ、HDD、SSD、光ディスク、磁気テープを使い分ける。
- キャッシュのヒット率と実効アクセス時間を計算する。
- バスの幅・周波数・転送回数から帯域を計算する。
- DMA、デバイスドライバ、接続規格の役割を説明する。
- 入力・表示・印刷・音声装置が現実の量とデジタル値を変換する仕組みを説明する。
- 論理回路、フリップフロップ、半導体、組込み制御、低消費電力設計の基礎を説明する。

すべての問題に解答と考え方があります。

## 学習の進め方

1. 第1話から順番に読みます。
2. 部品が出たら、「何を受け取るか」「何をするか」「何を渡すか」の3つを書きます。
3. 計算では、Hz、秒、ビット、バイトなどの単位を省略しません。
4. 各話の確認問題は、模範解答と照合し、自分の誤答がどの用語・条件・単位の取り違えから生じたか説明します。
   選択式の総合問題では、不採用選択肢の誤りも説明します。
5. 第16話は20問ずつ4回に分け、翌日に間違えた問題だけを解き直します。

CPUが命令を取り出しても、必要なデータがキャッシュになければ主記憶を待ちます。
装置へ仕事を渡せば、バスを通った指示が届き、割込みやDMAによって結果が戻ります。

CPUだけを速くしたときに、どの待ち時間が残るでしょうか。
その問いに、命令とデータの経路を指しながら答えられれば、コンピュータ全体の速さと限界を説明できます。
