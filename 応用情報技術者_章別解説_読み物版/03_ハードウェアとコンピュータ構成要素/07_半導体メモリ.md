# 第3章 第7話 半導体メモリ

主記憶もSSDも、半導体の微細なシリコンチップ内部に「0」と「1」のビット情報を記憶します。
しかし同じ半導体を用いた記憶媒体であっても、システムの電源を切った後の挙動はまったく同一ではありません。
主記憶として使われるDRAMは瞬時に内容が消失するのに対し、SSDに搭載されるフラッシュメモリは電源を切ってもデータが残り続けます。

日常会話における「メモリ」という単語は、データを保持する媒体全般の総称として使われることもあれば、PCの主記憶部品だけを指して呼ばれることも珍しくありません。
単にメモリと呼ぶだけでは、アクセス速度がどれほど速いのか、あるいは電源喪失時にデータが消えるか否かまでは判別できないわけです。

電子回路の電気的状態を利用してビットを記憶する**半導体メモリ**は、次のような多角的な視点を組み合わせて体系的に整理していきます。

- 電源を切った後も記録したデータが保持されるか
- データの読み取り専用か、それとも自由に書き換えられるか
- 読み書きに要するアクセスタイムがどれほど高速か
- 1ビットの記憶に要する回路面積や製造コストがどれほどか
- データの書き換えを何回まで繰り返すことができるか

## ビットの保持とアクセス方法を分ける

### 1 記憶セル

デジタル情報の最小単位である0または1のビットを物理的に保持する最小単位の電気回路を**記憶セル**（メモリセル）と呼びます。
半導体チップ内部では、この記憶セルを行と列の格子状（マトリクス状）に規則正しく並べることで、膨大なビットを整然と格納する構造が基本です。

```text
       列0 列1 列2 列3
行0     0   1   0   1
行1     1   1   0   0
行2     0   0   1   0
```

プロセッサからアドレス信号が入力されると、アドレス選択回路（デコーダ）が目的の行と列を特定します。
続いて読み出し回路が保持された電荷や電圧状態を検知して外部へ出力するか、あるいは書き込み回路が新たなビット情報をセルへ注入するわけです。

### 2 揮発性と不揮発性

電源の供給が途絶えると記憶していた内容が失われてしまう物理的性質を**揮発性**と呼びます。
これに対し、電源供給が絶たれた後も半減期や電荷トラップによって内容を長期間にわたり保持し続けられる性質が**不揮発性**です。

```text
揮発性:   作業中の主記憶、キャッシュなど
不揮発性: ファームウェア、保存データなど
```

不揮発性メモリであるからといって、永久にデータが消えないことを保証しているわけではありません。
半導体物理の観点からは、記録の保持保証年数や書き換え耐性回数、動作温度の上限といった明確な環境制約が存在します。

### 3 RAM

**RAM**（Random Access Memory）は、格納されているメモリ番地に関係なく、任意の場所へほぼ同一の所要時間で直接アクセスできるメモリの呼称です。
名称に含まれるrandomは無作為という意味合いよりも、先頭から順繰りにたどる磁気テープのようなシーケンシャルアクセスとは対照的に、任意のアドレスへ均等な速度で直接到達できる性質を表しています。
コンピュータの基本設計においては、プロセッサが頻繁に読み書きを行う主記憶の役割を担うのが通例です。
代表的な実装技術にはDRAMとSRAMが存在し、どちらも電源を落とすとデータが消滅する揮発性メモリに分類されます。

### 4 ROM

読み出しと書き込みを日常的に反復するRAMに対し、**ROM**（Read Only Memory）は主に読み出し専用として利用される不揮発性メモリです。
工場での製造工程時にデータを物理的に焼き込み二度と書き換えられない純粋なマスクROMだけでなく、専用の手順を踏むことでデータの更新が可能な各種のPROM系メモリも広く普及しています。
PCの電源投入時に真っ先に立ち上がるBIOS/UEFIなどのファームウェアや、組み込み機器の初期制御プログラムの格納場所として不可欠な存在と言えるでしょう。

## 高速な記憶と大容量の記憶を比べる

### 5 SRAM

同じRAMという枠組みに属していても、ビットを物理的に保持する内部回路の仕組みは大きく異なります。
**SRAM**（Static RAM）は、複数のトランジスタで構成されるフリップフロップ回路を用いて1ビットの二値状態を保持する仕組みです。
電源が供給されている限りは外部から電荷を定期的に再充電する必要がないため、「静的」を意味するstaticの冠が与えられています。

回路の応答速度が極めて高速であり、複雑な再充電制御を要しないため、CPU内部のキャッシュメモリや超高速バッファに最適な特性と言えるでしょう。
その反面、1ビットの記憶に4個から6個ものトランジスタを消費するため集積密度を高めにくく、ビット単価が非常に高価になる欠点を持ちます。
どれほど安定した保持特性を誇る構造であっても、電源遮断に伴って記憶内容が失われる揮発性メモリである点に変わりはありません。

### 6 DRAM

**DRAM**（Dynamic RAM）は、微小なコンデンサ（キャパシタ）に蓄積された電荷の有無によってビットの0と1を表現します。
1ビットのセルをわずか1個のトランジスタと1個のコンデンサという極小の部品点数で構成できるため、極めて高い集積度と大容量、そして安価なビット単価を実現しやすいのが最大の強みです。
この圧倒的な集積効率の高さこそが、コンピュータの広大な主記憶領域を一手に担う根拠と言えるでしょう。

しかし、コンデンサに蓄えられた微弱な電荷は、絶縁膜の隙間から時間の経過とともに少しずつ漏れ出てしまいます。
電荷が完全に抜けてビット情報が失われてしまう前に、一定周期ごとにデータを再読み出しして満充電し直す保守動作が欠かせません。
この動的な再書き込み動作こそが、リフレッシュと呼ばれる処理です。

### 7 DRAM読取りとリフレッシュ

DRAMの読み出し動作では、セル内の極微小な電荷をセンスアンプと呼ばれる高感度増幅回路で感知してロジックレベルを判定します。
コンデンサの微小電荷を外部へ引き出すとセル内の蓄積状態が破壊されてしまうため、読み出し動作の直後には必ず元の電荷を復元する再書き込みが行われる仕様です。

リフレッシュの実行中はプロセッサからの通常のメモリアクセスが一時的に待たされる形となり、動作電力も消費します。
半導体の容量がギガバイト単位へと大容量化するほど、定期保守すべきセルの総数とリフレッシュにかかるオーバーヘッドは無視できない規模に達します。
dynamicという名称はデータの内容がひとりでに変貌するという意味合いにとどまらず、電荷を維持するために動的なリフレッシュ動作を絶え間なく繰り返す構造に由来しているわけです。

### 8 SRAMとDRAMの比較

両者の物理特性と得手不得手を対照表として整理してみましょう。

| 観点 | SRAM | DRAM |
|---|---|---|
| 主な保持回路 | 複数トランジスタの状態 | コンデンサの電荷など |
| リフレッシュ | 不要 | 必要 |
| 速度 | 速い | SRAMより遅い |
| 密度 | 低い | 高い |
| 容量当たり費用 | 高い | 低い |
| 主用途 | キャッシュ | 主記憶 |
| 電源断 | 消える | 消える |

「SRAMはstatic（静的）と呼ばれるから不揮発性である」という思い込みは代表的な初学者の誤解です。
両者ともに電源の供給が途絶えればビットを失う揮発性メモリである事実を正しく把握しておかなければなりません。

## 主記憶をクロックに合わせて動かす

### 9 SDRAM

DRAMセルによる電荷保持の仕組みを基礎としつつ、外部のシステムバスとデータをやり取りする通信タイミングを洗練させた技術が存在します。
外部のシステムクロック信号に同期してコマンド受付やデータ入出力を行うアーキテクチャが、SDRAM（Synchronous DRAM）です。
あらかじめ指示された行を開き、列を指定した後に連続するデータをクロックの拍子に合わせて一気に流し込むバースト転送など、クロック基準の高効率なメモリアクセスを実現しています。

### 10 DDR SDRAM

クロック同期による高速データ転送をさらに倍加させる技術が、DDR（Double Data Rate）方式です。
矩形波であるクロック信号の立ち上がりエッジと立ち下がりエッジの両方のタイミングを利用し、1周期の間に2倍のデータ転送を実行します。

技術の進展に伴い、DDR、DDR2、DDR3、DDR4、DDR5へと世代交代が重ねられ、動作周波数や内部バンク数、駆動電圧の低減が図られてきました。
世代が異なるモジュール同士は切り欠きの位置や動作電圧、内部コマンド体系が根本から異なるため、物理的な互換性はありません。
また、規格上の世代が進んでデータ転送帯域が飛躍的に広がったとしても、1回のアクセス要求を発行してから最初のデータが返るまでのレイテンシ（絶対遅延時間）が同等に短縮されるとは限らない点に留意が必要です。

### 11 DIMMとSO-DIMM

半導体チップ単体の仕様だけでなく、マザーボードのスロットに差し込む基板モジュールの物理的形状も規格化されています。
複数のDRAMチップと制御用回路を細長いプリント基板上に実装し、着脱可能な規格品として仕上げたものがメモリモジュールです。

- DIMM（Dual Inline Memory Module）はデスクトップPCやサーバで広く採用される標準サイズのモジュールです。
- SO-DIMM（Small Outline DIMM）は省スペース設計のノートPCや小型機器に向けて小型化された基板規格を指します。

規格に合致したモジュールを選定する際は、基板の外形寸法だけでなく、DDRの世代番号、クロック周波数、誤り訂正機能の有無、システムの対応上限容量を漏れなく合致させなければなりません。

## 消去と書換えの方法を選ぶ

### 12 マスクROM

SRAMやDRAMが電源稼働中の読み書き性能を最優先した揮発性メモリであるのに対し、電源を切った後もデータを長期間保持するためには不揮発性の技術体系が用いられます。
集積回路の製造プロセスにおいて、フォトマスクを用いた露光・エッチング工程の段階でデータ配線を物理的に焼き固めてしまうメモリがマスクROMです。
固定するプログラム内容が完全に確定した民生品を数十万個規模で大量生産する場合、1チップあたりの製造原価を極めて低廉に抑えられます。
その一方で、回路設計の変更には莫大なマスク作成費用と製造リードタイムを要し、出荷後に内容を書き換えることは一切不可能です。

### 13 PROM

半導体メーカーからの出荷時にはブランク（未書き込み）のまま出荷され、システムの開発者や製造ラインの手元でデータを後から書き込める製品をPROM（Programmable ROM）と総称します。
内部に微細なヒューズ回路を備え、専用のROMライタで過電流を流して配線を不可逆的に焼き切ることでビット列を記録する方式です。
一度書き込みを行ったビットは二度と元に戻すことができず、プログラムにバグが見つかった場合の修正や再利用は効きません。

### 14 EPROM

記録した内容を後から消去し、チップを再利用できるように改良されたデバイスがEPROM（Erasable PROM）です。
パッケージの中央に紫外線を透過する石英ガラスの窓が設けられており、高エネルギーの紫外線をチップ全面に一定時間照射することで浮遊ゲートの電荷を放電させ、データを一括消去します。
内容を更新する際には基板のソケットからチップを物理的に取り外し、専用の紫外線照射器と書き込み機器を用意しなければなりませんでした。
電子回路に組み込んだまま電気信号だけで部分的にデータを書き換える用途には、明らかに不向きな仕様と言わざるを得ません。

### 15 EEPROM

紫外線の代わりに電気的な高電圧パルスを用いてデータを消去・再書き込みできるように進化させた不揮発性メモリがEEPROM（Electrically Erasable PROM）です。
回路基板にハンダ付けした実装状態のまま、1バイト単位やワード単位といった小さなデータ粒度で局所的な書き換えを実行できます。
機器の固有MACアドレスや各種のキャリブレーション値、電源切断時も保持したい環境設定パラメータの記録場所として重宝されてきました。
ただし通常のRAMに比べて書き込み動作に長時間を要し、素子の絶縁酸化膜が徐々に劣化するため書き換え可能回数には物理的な上限が定められています。

## 大容量の保存に使う記憶を比べる

### 16 フラッシュメモリ

EEPROMの技術を母体としながら、消去動作を従来のバイト単位から一定サイズのブロック単位へと改め、まとめて実行することにより、飛躍的な高集積化と大容量化を成し遂げたメモリが**フラッシュメモリ**です。
PCのSSDやスマートフォンの内蔵ストレージ、USBメモリ、SDカードなど、現代のデジタル機器における二次記憶媒体の中核を担っています。

フラッシュメモリのセル構造は、既存のデータに対して直接上書き（インプレース更新）を行うことができません。
データの書き込みはあらかじめ消去された空きページに対して行い、不要となったデータの消去は複数ページを束ねた巨大なブロック単位で一括実行する独特の制約を負っています。
記憶領域の偏った劣化を防ぎつつ効率的なデータ更新を実現するため、内蔵のメモリコントローラがアドレス変換やブロック管理を統合的に制御する構成が不可欠です。

### 17 NORフラッシュ

フラッシュメモリの内部構造のうち、記憶セルをビット線に対して並列に接続した回路方式をNORフラッシュと呼びます。
任意のアドレスに対するランダム読み出しが極めて高速であり、CPUが直接アドレスバスを介してコードをそのまま実行できる利点を備えた回路方式です。
ルータや産業用機器のブートローダ、マイコンのファームウェア格納領域に好んで採用される構成と言えるでしょう。
その一方でセル面積が大きくなりやすく、大容量化を図る用途には向かない構造的な制約を抱えています。

### 18 NANDフラッシュ

NOR型とは対照的に、複数の記憶セルを数珠つなぎの直列状に接続してビット線へ結びつける回路トポロジがNANDフラッシュです。
選択トランジスタの数を大幅に削減できるためセルの専有面積が極めて小さく、高集積・大容量・低価格の三拍子が揃ったストレージメディアを実現できます。
バイト単位のランダムアクセスは行えず、ページ単位での読み出しやブロック単位の一括消去に特化した動作体系をとるのが特徴です。
SSDやメモリーカードの実装にあたっては、書き換え寿命の偏りを平準化するウェアレベリングや、不良ブロックの代替処理、誤り訂正回路の支援が必須となります。

NOR型とNAND型の呼称は論理ゲートのNOR回路・NAND回路に似た配線形態に由来するものですが、学習上は内部の接続構造と得意とする用途の違いを明確に峻別することが重要です。

### 19 SLC、MLC、TLC、QLC

フラッシュメモリの大容量化は、微細化技術によるセルの物理的な増設だけでなく、1個の記憶セルに複数ビットの情報を多値記録するアプローチによっても推し進められてきました。
1個のセルに蓄える電子の量を多段階に精密制御し、何ビットのデータを持たせるかによって素子のグレードが分類されます。

- SLC（Single Level Cell）は1セルに1ビットを記録し、2段階の電圧状態を識別する設計です。
- MLC（Multi Level Cell）は一般に1セルに2ビットを保持し、4段階の電圧状態を区別します。
- TLC（Triple Level Cell）は1セルに3ビットを収容し、8段階の微小な電圧差を識別する構成です。
- QLC（Quad Level Cell）は1セルに4ビットを詰め込み、実に16段階もの電圧閾値を精密に制御します。

1セルあたりの記録ビット数を増やせば、同一のシリコン面積に記録できる容量が飛躍的に増大し、ビット単価を劇的に引き下げることが可能です。
しかし、識別すべき電圧の閾値差が微小になるほどノイズマージンが削られ、書き込み・消去速度の低下やセルの絶縁膜劣化に伴う書き換え寿命の大幅な短縮を招きます。
容量の拡大と信頼性・耐久性との間には、物理法則に根ざした強いトレードオフ関係が横たわっていると言えるでしょう。

## 保持方法とモジュール全体の条件を確かめる

### 20 FeRAM

電荷の蓄積とは異なる物理現象を活用した次世代の不揮発性メモリとして、強誘電体の自発分極現象を応用したFeRAM（Ferroelectric RAM）が挙げられます。
外部電界によって生じる強誘電体膜の分極方向を利用してビットを記録し、電源切断後もその配向状態が保持される構造です。
高速な書き込み性能を誇り、フラッシュメモリを桁違いに上回る書き換え耐性回数と低消費電力を両立しています。
製造工程の複雑さやコストの制約から大容量化は容易でないものの、ICカードや産業計測機器の設定保持領域で広く活躍していると言えるでしょう。

### 21 主記憶の構成

個々の記憶セルの物理的特性を把握しただけでは、システム全体としてのメモリアーキテクチャを理解したことにはなりません。
プロセッサと何本のアドレス線で接続され、1回のアクセスで何ビットのデータ幅をやり取りし、伝送エラーをどのように防ぐかという組織構造の把握が不可欠です。

主記憶ユニットの内部は、記憶セル配列を取り囲むように以下の機能ブロックによって構成されています。

```text
アドレス
  ↓
アドレス選択機構・デコーダ
  ↓
記憶セル配列
  ↕
読取り・書込み回路
  ↕
データ線
```

アドレス線に入力された番地情報はデコーダによって行選択線と列選択線に分解され、配列上の目的セルを特定する仕組みです。
同時に制御線から供給されるリード／ライト信号やクロック信号に従って、読み出し回路と書き込み回路が正確なタイミングでデータバスと信号を授受します。

## 番地数と誤りへの対策を計算する

### 22 容量の計算

アドレス信号を伝送する物理配線（アドレス線）がn本存在する場合、表現できるビットの組み合わせパターンは「2のn乗」通りとなります。
したがって、プロセッサが直接指定できる記憶番地の総数は最大で2ⁿ個です。

コンピュータの世界でメモリ容量を正確に表記する際は、IECが定めた二進接頭辞を用いるのが標準的なルールと言えるでしょう。

```text
1KiB = 2¹⁰B = 1,024B
1MiB = 2²⁰B = 1,048,576B
1GiB = 2³⁰B = 1,073,741,824B
```

これらは10の累乗を基準とするSI接頭辞（1kB = 1,000B、1MB = 1,000,000B、1GB = 1,000,000,000B）とは数値の大きさが明確に異なります。
資格試験などの計算問題にあたっては、問題文で指定された接頭辞の定義を厳格に確認し、単位系が混在している場合はバイト数に換算して計算を進めなければなりません。

たとえば、アドレス線が20本あり、1番地あたり8ビット（1バイト）のデータを格納するメモリ構成を考えてみましょう。

```text
番地数 = 2²⁰
一番地 = 1バイト
容量 = 2²⁰バイト = 1MiB
```

もしデータバス幅が16ビットであり、1番地あたり16ビット（2バイト）を格納する仕様であれば、同じアドレス線20本であっても総容量は2倍の2MiBへと拡大します。
問題文を読み解く際は、番地数だけでなく「1番地が何ビットで定義されているか」を漏れなく見極める姿勢が不可欠です。

### 23 パリティ

物理的なメモリ容量の算出に加えて、データ保持中や信号伝送中にノイズ等でビット値が反転してしまう障害への対策も押さえておかなければなりません。
元のデータビット列に対して1ビットの検査用ビットを付加し、値の反転を簡易的に検知する代表的な手法がパリティチェックです。

偶数パリティ方式を採用する場合、データビットとパリティビットを合算したビット列全体の中で「1」の個数が常に偶数となるよう検査ビットの値を決定します。

```text
データ 1011001  1は4個
パリティ 0     合計4個で偶数
```

伝送途中でいずれか1ビットが反転した場合、1の総数が奇数に変化するため、誤りの発生を直ちに検知できるわけです。
ただし、偶数個のビットが同時に反転した場合は誤りをすり抜けてしまう限界があり、どの位置のビットが化けたのかを特定して修復することはできません。

### 24 ECC

パリティのようにエラーを検出するだけでなく、化けてしまったビットの反転位置を数学的に突き止めて自動修復する高度な仕組みが**ECC**（Error Correcting Code、誤り訂正符号）です。
データビット列に対して複数の検査用ビット（シンドローム生成ビット）を付加し、ハミング符号などの代数的なアルゴリズムを用いて誤り訂正を実現します。

サーバ向けの高信頼主記憶モジュールでは、1ビットの誤りを訂正しつつ2ビットの誤りを検出するSEC-DED方式がデファクトスタンダードです。
宇宙線や放射線に起因する中性子線の衝突などで引き起こされる一時的なソフトエラーからシステムを堅牢に防護します。
ただし、いかにECCを搭載しているからといって、訂正能力の限界を超える多重ビット破壊や物理的なチップ破損まで万能に救済できるわけではありません。

## 用途に合うメモリを選ぶ

### 25 メモリ選定

CPUキャッシュに求められる極限の応答速度、主記憶に求められる巨大な容量と経済性、ストレージに求められる電源切断時のデータ保持など、システムの用途によって要求される物理特性は千差万別です。
ここまで解説してきた半導体メモリの動作原理と記録特性を、代表的な適用領域と照合して整理してみましょう。

| 用途 | 選びやすいもの | 理由 |
|---|---|---|
| CPUキャッシュ | SRAM | 高速 |
| 大容量主記憶 | DRAM | 高密度、容量当たり低価格 |
| 固定ファームウェア大量生産 | マスクROM | 製造時固定で量産向き |
| 少量設定値 | EEPROM、FeRAM | 電気的更新、不揮発 |
| 大容量保存 | NANDフラッシュ | 高密度、大容量 |
| 直接実行する組込みコード | NORフラッシュ | ランダム読出し向き |

実際のハードウェア設計においては、単一の性能指標だけでなく、要求容量、アクセス遅延、書き換え可能回数、消費電力、耐熱温度、調達コスト、長期供給保証といった多様な要件を総合的に勘案して最適なデバイスを選定していきます。
