# 第1章7 グラフ理論――つながりを点と線へ置き換える

## 地図の細部を捨てると、経路が見える

道路地図から建物の形や看板を消しても、交差点どうしの経路は求められます。
しかし、一方通行の向きまで消すと、通れない帰路を最短経路として選ぶかもしれません。

細部を残しすぎれば計算しにくくなり、捨てすぎれば別の問題になります。
点と線へ置き換える前に、答えを変える情報と変えない情報を分けなければなりません。

## 1 抽象化――必要な関係だけを残す

3つの駅A、B、Cがあります。
実際の駅には建物、改札、売店などがあります。
しかし「どの駅からどの駅に直接行けるか」だけを考えたいなら、すべてを描く必要はありません。

駅を点、直接つながる線路を線で表します。

```text
A ─── B ─── C
```

現実の対象から、目的に必要な特徴だけを取り出すことを**抽象化**と呼びます。

このように、対象を点、対象同士の関係を線で表した数学的な構造が**グラフ**です。
棒グラフや折れ線グラフの「グラフ」と同じ言葉ですが、ここではつながりの構造を指します。

点を**頂点**またはノード、線を**辺**またはエッジと呼びます。

```text
駅、人、Webページ、作業  → 頂点
線路、友人関係、リンク、前後関係 → 辺
```

## 2 向きがある辺と、ない辺

2点がつながっているという情報だけでは、往復できるかどうかは分かりません。

友人関係を「互いに友人」と考えるなら、AとBの関係に向きはありません。
このグラフを**無向グラフ**と呼びます。

```text
A ─ B
```

WebページAからBへのリンクがあっても、BからAへのリンクがあるとは限りません。
向きがある辺を矢印で描きます。
このグラフを**有向グラフ**と呼びます。

```text
A → B
```

矢印はAからBに進めることを表します。
逆向きに進めるとは限りません。

道路でも、一方通行なら有向、双方向に通れるなら無向として表せます。
現実の関係に合わせて選びます。

## 3 辺へ距離や費用を付ける

向きまで残しても、到達できる経路が複数あれば、どれを選ぶべきかは決まりません。

駅間の所要時間を辺に書きます。

```text
A --5分-- B --3分-- C
 \                       /
  -------12分------------
```

辺に付けた数を**重み**と呼び、このようなグラフを**重み付きグラフ**と呼びます。

重みは距離だけではありません。

- 移動時間
- 運賃
- 通信遅延
- 工事費
- 危険度

「最もよい経路」を考える前に、何を小さくしたいかを決めます。
最短距離と最短時間と最低運賃は、別の経路になる場合があります。

## 4 経路、閉路、連結

辺を順にたどって頂点から別の頂点に進む道筋を**経路**と呼びます。

```text
A → B → C
```

出発した頂点に戻る経路を**閉路**と呼びます。

```text
A → B → C → A
```

無向グラフで、どの2頂点の間にも経路がある状態を**連結**と呼びます。
連結でなければ、いくつかの離れたかたまりに分かれています。

有向グラフでは、向きに従って互いに到達できるかを区別します。
すべての頂点対で双方向に到達できる状態は強連結です。

## 5 次数――一つの頂点へ何本つながるか

無向グラフで、ある頂点に接続する辺の本数を**次数**と呼びます。

```text
    B
    |
C ─ A ─ D
```

Aの次数は3、B、C、Dの次数は各1です。

有向グラフでは、入ってくる辺の本数を入次数、出ていく辺の本数を出次数と呼びます。

全頂点の次数を足すと、無向グラフでは辺数の2倍になります。
1辺は両端の頂点で1回ずつ数えられるからです。

```text
全頂点の次数の合計 = 2 × 辺の本数
```

## 6 木――つながっているが輪がない

すべての頂点がつながり、閉路を持たない無向グラフを**木**と呼びます。

```text
    A
   / \
  B   C
     / \
    D   E
```

木には、2頂点間の経路が1つだけという性質があります。
別の経路が2つあれば、それらを合わせて閉路ができるためです。

頂点が`n`個の木では、辺は`n-1`本です。

5頂点の上の木なら辺は4本です。

### なぜn-1本か

最初の頂点は1個だけで、辺は不要です。
新しい頂点を、既存の木に1辺でつなぐ操作を繰り返します。

```text
頂点1個  辺0本
頂点2個  辺1本
頂点3個  辺2本
   …
頂点n個  辺n-1本
```

1辺より多く加えて新頂点をつなぐと閉路ができる可能性があります。
1辺も加えなければ全体につながりません。

## 7 根付き木

木の1頂点を出発点として選び、上下関係を付けたものが**根付き木**です。
最上位の頂点を根、下の頂点を子、その1段上を親と呼びます。

```text
       根 A
      /   \
   子B    子C
          / \
         D   E
```

フォルダ、会社組織、分類などを表せます。
ただし現実の組織で1人が複数部署に所属するなら、単純な木では表せません。
モデルの前提を確認します。

## 8 最短経路問題

出発点Aから目的地Dまで、辺の重みの合計が最小になる経路を探す問題が**最短経路問題**です。

```text
A --2-- B --3-- D
 \              /
  --4-- C --2--
```

2つの候補を比べます。

```text
A→B→D: 2+3=5
A→C→D: 4+2=6
```

AからDの最短経路はA→B→Dで、重みは5です。

重みが時間なら最短時間、費用なら最小費用です。
「最短」という言葉でも、重みが何かを確認します。

辺の重みがすべて0以上なら、現在分かっている距離が最小の未確定頂点から順に確定するダイクストラ法を使えます。
詳しい手順は第2章で扱います。

## 9 最小全域木

複数の町すべてに通信線を引きたいとします。
どの町からも別の町に通信できればよく、線の総工事費を最小にしたい問題です。

すべての頂点を含む木を**全域木**と呼びます。
そのうち辺の重み合計が最小のものが**最小全域木**です。

最短経路と目的を比べます。

```text
最短経路
  一つの出発点から一つまたは各目的地までの移動費を小さくする

最小全域木
  全頂点をつなぐ辺全体の合計費用を小さくする
```

辺の総費用が最小なら、その木の中にある2点間の道も最短になるように思えます。
しかし、最小全域木で、ある2点間の道が最短とは限りません。
全体を安くつなぐため、個別の移動では遠回りを許す場合があります。

代表的な求め方に、安い辺から閉路を作らないよう加えるクラスカル法、現在つながった集合から外に最も安い辺を伸ばすプリム法があります。
第2章で手順を追います。

## 10 隣接行列で保存する

コンピュータにグラフを保存する方法を考えます。

頂点A、B、Cがあり、A-B、A-Cに辺があるとします。
縦横に全頂点を並べ、辺があれば1、なければ0を書きます。

```text
    A B C
A   0 1 1
B   1 0 0
C   1 0 0
```

この表を**隣接行列**と呼びます。

無向グラフではA-BがあればB-Aもあるため、左上から右下の線を境に対称になります。
自分自身への辺がなければ対角は0です。

全頂点を縦横に並べる隣接行列は、接続の有無を同じ形で調べられるため、扱いやすく見えます。
しかし、辺が少なくても表の大きさは変わりません。

### 隣接行列の特徴

- AとBが直接つながるか、1か所を見れば分かる。
- 頂点が`n`個なら、辺が少なくても`n×n=n²`個の場所を使う。
- 辺が密集したグラフや、2頂点の直接接続を何度も調べる処理に向く。

## 11 隣接リストで保存する

各頂点について、実際につながる相手だけを並べます。

```text
A: B, C
B: A
C: A
```

この保存方法を**隣接リスト**と呼びます。

### 隣接リストの特徴

- 存在する辺を中心に保存する。
- 辺が少ないグラフで場所を節約できる。
- ある頂点からつながる相手を順に調べやすい。
- 特定の2頂点が直接つながるかは、相手一覧を探す必要がある場合がある。

同じ数学的グラフでも、保存方法が処理時間とメモリ使用量を変えます。

## 12 現実をグラフへ変えるときの判断

グラフの計算法が正しくても、現実のモデルが間違っていれば答えは役立ちません。

道路経路なら、次を決める必要があります。

- 一方通行を有向辺で表したか。
- 右左折禁止を単純な辺だけで表せるか。
- 時間帯で変わる所要時間をどう扱うか。
- 通行止めをいつ更新するか。
- 距離、時間、料金のどれを重みにするか。

SNSの関係なら、「フォロー」と「友人」を同じ無向辺にしないようにします。
業務の依存関係なら、作業Aが終わるまでBを始められない向きを正しく付けます。

抽象化では、何を捨てたかを意識します。


## 13 確認問題

1. 数学のグラフにおける頂点と辺を、駅の例で説明してください。
2. 有向グラフと無向グラフの違いを説明してください。
3. 重みにはどのような量を置けますか。
   三例挙げてください。
4. 経路と閉路の違いを説明してください。
5. 5頂点の木には辺が何本ありますか。
   理由も説明してください。
6. 最短経路と最小全域木の目的の違いを説明してください。
7. 頂点が1000個、辺が100本しかない場合、隣接行列と隣接リストのどちらが保存場所を節約しやすいですか。
8. 無向グラフで、各頂点の次数が`3,2,2,1`なら、辺は何本ありますか。
9. A-Bが2、B-Cが5、A-Cが10のとき、AからCへの最短経路と重みを求めてください。
10. 道路をグラフに置き換えるとき、単純な距離以外に考慮すべき条件を2つ挙げてください。

## 解答と考え方

1. **考え方**：定義、対象、役割、成立条件を整理し、似た用語との境界を確認します。
   **解答**：駅を頂点、駅間を直接つなぐ線路を辺として表します。
   駅舎など、接続関係に不要な情報は省略します。
   **誤答しやすい理由**：略語展開や日常語の印象だけでは、対象・役割・成立条件のいずれかが抜け、近い用語と区別できません。
   **復習箇所**：[第1章7 グラフ理論――つながりを点と線に置き換える](#第1章7 グラフ理論――つながりを点と線へ置き換える)を参照してください。
2. **考え方**：対象、目的、成立条件、失敗時を同じ軸で比べます。
   **解答**：有向グラフの辺には進める向きがあり、逆向きがあるとは限りません。
   無向グラフの辺は双方向の関係として扱います。
   **誤答しやすい理由**：名称や長所だけで選ぶと、守る対象・処理時点・前提条件が違う方式を交換可能だと誤認します。
   **復習箇所**：[第1章7 グラフ理論――つながりを点と線に置き換える](#第1章7 グラフ理論――つながりを点と線へ置き換える)を参照してください。
3. **考え方**：定義、対象、役割、成立条件を整理し、似た用語との境界を確認します。
   **解答**：距離、所要時間、料金、通信遅延、工事費、危険度などです。
   何を最小化したいかに合わせます。
   **誤答しやすい理由**：略語展開や日常語の印象だけでは、対象・役割・成立条件のいずれかが抜け、近い用語と区別できません。
   **復習箇所**：[第1章7 グラフ理論――つながりを点と線に置き換える](#第1章7 グラフ理論――つながりを点と線へ置き換える)を参照してください。
4. **考え方**：対象、目的、成立条件、失敗時を同じ軸で比べます。
   **解答**：経路は辺をたどる道筋です。
   閉路は出発した頂点に戻る経路です。
   **誤答しやすい理由**：名称や長所だけで選ぶと、守る対象・処理時点・前提条件が違う方式を交換可能だと誤認します。
   **復習箇所**：[4 経路、閉路、連結](#4 経路、閉路、連結)を参照してください。
5. **考え方**：求める量と単位をそろえ、関係式、代入、結果の順に計算します。
   **解答**：4本です。
   `n`頂点の木は、全体をつなぎ閉路を持たないため`n-1`本の辺を持ちます。
   **誤答しやすい理由**：途中式を飛ばすと、切上げ・分母・時間換算・2進/10進接頭辞のどこで値が変わったか検算できません。
   **復習箇所**：[5 次数――1つの頂点に何本つながるか](#5 次数――一つの頂点へ何本つながるか)を参照してください。
6. **考え方**：対象、目的、成立条件、失敗時を同じ軸で比べます。
   **解答**：最短経路は指定した出発点から目的地までの重み合計を小さくします。
   最小全域木は全頂点をつなぐ辺の総費用を小さくします。
   **誤答しやすい理由**：名称や長所だけで選ぶと、守る対象・処理時点・前提条件が違う方式を交換可能だと誤認します。
   **復習箇所**：[9 最小全域木](#9 最小全域木)を参照してください。
7. **考え方**：対象、目的、成立条件、失敗時を同じ軸で比べます。
   **解答**：隣接リストです。
   隣接行列は辺が少なくても1000×1000個の欄を使います。
   **誤答しやすい理由**：名称や長所だけで選ぶと、守る対象・処理時点・前提条件が違う方式を交換可能だと誤認します。
   **復習箇所**：[10 隣接行列で保存する](#10 隣接行列で保存する)を参照してください。
8. **考え方**：求める量と単位をそろえ、関係式、代入、結果の順に計算します。
   **解答**：次数合計は`3+2+2+1=8`です。
   1辺を両端で2回数えているため、辺数は`8÷2=4本`です。
   **誤答しやすい理由**：途中式を飛ばすと、切上げ・分母・時間換算・2進/10進接頭辞のどこで値が変わったか検算できません。

   A-B-Cは`2+5=7`なので、最短経路はA→B→C、重み7です。
