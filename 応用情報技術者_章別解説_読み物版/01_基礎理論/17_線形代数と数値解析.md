# 第1章・第17話　線形代数と数値解析――たくさんの数と、解けない式を扱う道具


## 1 スカラー――一個だけの数

温度が25℃、人数が40人、処理時間が2.5秒というように、一個の数だけで表せる量をスカラーと呼びます。

```text
温度 = 25
人数 = 40
時間 = 2.5
```

「スカラー」は特別な計算法の名前ではありません。「一個の数として扱っている」と区別するための名前です。

## 2 ベクトル――順番のある数の列

ある地点を、横方向の位置`x=3`、縦方向の位置`y=2`で表します。

```text
(3, 2)
```

このような順番のある数の列をベクトルと呼びます。

順番には意味があります。`(3,2)`と`(2,3)`は違う地点です。

ベクトルは、位置だけでなく、次のようなものを表せます。

- 速度：東へ3、北へ2。
- 商品の個数：鉛筆3本、消しゴム2個。
- 色：赤の強さ200、緑100、青50。
- 人の特徴：身長、体重、年齢。

### ベクトルの足し算

東へ3、北へ2進んだ後、東へ1、北へ4進みます。

```text
(3,2) + (1,4) = (4,6)
```

同じ位置どうしを足します。

### スカラー倍

ベクトルを一個の数で何倍かします。

```text
2 × (3,2) = (6,4)
```

向きは同じまま、長さが二倍になります。負の数を掛ければ、向きが反対になります。

## 3 内積――二つの向きが、どれほど同じか

二つのベクトル、`a=(a₁,a₂)`と`b=(b₁,b₂)`の内積は、

```text
a・b = a₁×b₁ + a₂×b₂
```

です。

例えば、

```text
(3,2)・(4,1) = 3×4 + 2×1 = 14
```

です。

内積には、二つの向きがどれほど同じ方向を向くかを測る意味があります。

- 同じ方向に近い：正で大きくなりやすい。
- 直角：0。
- 反対方向：負になる。

検索や機械学習では、文章や利用者の好みを長いベクトルにし、内積やコサイン類似度で似ている度合いを測ることがあります。

## 4 行列――数を長方形に並べた表

次のような数の表を行列と呼びます。

```text
A = [1  2  3]
    [4  5  6]
```

横の並びを行、縦の並びを列と呼びます。この行列は二行三列です。

行列は、ただの表としてデータを保存することもあれば、ベクトルを別のベクトルへ変える規則を表すこともあります。

## 5 転置行列――行と列を入れ替える

行列`A`の行と列を入れ替えたものを転置行列と呼び、`Aᵀ`と書きます。

```text
A  = [1  2  3]
     [4  5  6]

Aᵀ = [1  4]
     [2  5]
     [3  6]
```

二行三列が、三行二列になりました。

転置は、縦向きのベクトルを横向きにしたり、行列の積で内積をまとめて計算したりするときに使います。

## 6 行列の足し算とスカラー倍

同じ大きさの行列どうしは、同じ場所の数を足します。

```text
[1 2] + [5 6] = [6  8]
[3 4]   [7 8]   [10 12]
```

スカラー倍では、すべての要素に同じ数を掛けます。

```text
2 × [1 2] = [2 4]
    [3 4]   [6 8]
```

## 7 行列とベクトルの掛け算――複数の式を一度に計算する

次の計算を見ます。

```text
[2 1] [3] = [2×3 + 1×4] = [10]
[0 5] [4]   [0×3 + 5×4]   [20]
```

左の行列の各行と、右のベクトルの内積を求めています。

これは二つの式、

```text
2x + y
0x + 5y
```

へ`x=3, y=4`を入れた結果を、一度に計算したものです。

### 掛けられる大きさ

`m行n列`の行列と、`n行p列`の行列を掛けると、`m行p列`になります。

真ん中の`n`が一致する必要があります。

```text
(m×n) × (n×p) → (m×p)
```

行列の掛け算は一般に順番を入れ替えられません。`AB`が計算できても`BA`が計算できない場合があり、両方計算できても値が違う場合があります。

## 8 単位行列――掛けても変えない行列

数の1は、何かへ掛けても値を変えません。

```text
1×7=7
```

行列にも同じ役割のものがあります。対角線に1、それ以外に0が並ぶ単位行列です。

```text
I = [1 0]
    [0 1]
```

どの二次元ベクトルへ掛けても変わりません。

```text
[1 0][x] = [x]
[0 1][y]   [y]
```

## 9 逆行列――行列による変換を元へ戻す

数`2`を掛けた操作は、`1/2`を掛けると元へ戻せます。

```text
2 × (1/2) = 1
```

行列`A`について、掛けると単位行列になる行列を逆行列と呼び、`A⁻¹`と書きます。

```text
A A⁻¹ = A⁻¹ A = I
```

すべての行列に逆行列があるわけではありません。例えば、二次元の面全体を一本の線へ押しつぶす変換は、どの元の点だったか分からなくなるため、完全には戻せません。

二行二列の行列、

```text
A = [a b]
    [c d]
```

では、`ad-bc`が0でなければ逆行列があります。

```text
A⁻¹ = 1/(ad-bc) × [ d -b]
                       [-c  a]
```

`ad-bc`を行列式と呼びます。行列式が0なら、空間を押しつぶして情報を失うため、逆行列を作れません。

大規模な計算では、逆行列そのものを求めるより、後で学ぶ消去法などで連立方程式を直接解く方が、速く安定な場合があります。

## 10 テンソル――さらに多くの方向へ並べた数

用語の関係を、まず単純化して整理します。

```text
スカラー：0方向に広がる一個の数
ベクトル：1方向に並ぶ数
行列：2方向、つまり行と列に並ぶ数
テンソル：一般に、さらに多くの方向へ並ぶ数
```

例えば、カラー画像一枚は、

- 高さ
- 幅
- 色の三成分

という三方向に数が並んだテンソルとして扱えます。

複数のカラー画像をまとめると、

- 画像番号
- 高さ
- 幅
- 色

の四方向になります。

機械学習用ライブラリでは、多次元配列を広くテンソルと呼びます。数学での厳密なテンソルは、座標を変えたときの変換規則まで含む概念ですが、初学段階では「多方向へ並ぶ数の集まり」という入口から始めて構いません。

## 11 連立方程式を行列で書く

次の二つの式を同時に満たす`x,y`を求めます。

```text
2x + y = 5
x - y = 1
```

係数を行列にまとめます。

```text
[2  1][x] = [5]
[1 -1][y]   [1]
```

短く、

```text
Ax=b
```

と書けます。

もし`A⁻¹`があるなら、左から掛けて、

```text
A⁻¹Ax = A⁻¹b
Ix = A⁻¹b
x = A⁻¹b
```

と解けます。ここで太字でない`x`は、実際には複数の未知数を並べたベクトルを表しています。

## 12 ガウスの消去法――式を少しずつ簡単にする

先ほどの連立方程式を解きます。

```text
2x + y = 5    …(1)
 x - y = 1    …(2)
```

式(2)を二倍します。

```text
2x - 2y = 2
```

式(1)から引くと、`x`が消えます。

```text
(2x+y) - (2x-2y) = 5-2
3y = 3
y = 1
```

式(2)へ戻すと、

```text
x - 1 = 1
x = 2
```

です。

ガウスの消去法は、この「ある式の何倍かを別の式へ足し、未知数を一つずつ消す」作業を、行列へ規則的に行います。

### 拡大係数行列

式の係数と右辺だけを並べます。

```text
[2  1 | 5]
[1 -1 | 1]
```

行に対して、次の操作をしても解は変わりません。

- 二つの行を入れ替える。
- 一つの行を0でない数倍する。
- 一つの行の何倍かを、別の行へ足す。

最終的に階段状にし、下の式から順に未知数を決めることを後退代入と呼びます。

### ピボット選択

ある値で割るとき、その値をピボットと呼びます。ピボットが0なら割れません。非常に小さい値でも、丸め誤差が大きくなる恐れがあります。

そこで、下の行も含めて絶対値が大きい値を持つ行と入れ替える部分ピボット選択を行うことがあります。数学上同じ答えでも、計算手順により数値的な安定性が違います。

## 13 固有ベクトル――変換しても向きが変わらない方向

行列`A`は、ベクトルを別のベクトルへ変えます。普通は、長さも向きも変わります。

しかし、特別な方向のベクトル`v`では、行列を掛けても向きが変わらず、長さだけが`λ`倍になることがあります。

```text
Av = λv
```

- `v`を固有ベクトル。
- `λ`を固有値。

と呼びます。`λ`はラムダと読みます。

### 小さな例

```text
A = [2 0]
    [0 3]
```

横向きのベクトル`v=(1,0)`へ掛けます。

```text
Av = (2,0) = 2v
```

向きは横のまま、長さが二倍です。したがって、`(1,0)`は固有ベクトル、`2`は対応する固有値です。

縦向きの`(0,1)`なら、

```text
A(0,1) = (0,3) = 3(0,1)
```

なので、固有値は3です。

### なぜ役立つのか

複雑な変換でも、「向きが変わらず、何倍になるか」へ分解できると、繰り返し変換した先を理解しやすくなります。

- マルコフ過程の定常分布。
- 主成分分析で、ばらつきが大きい方向を探す。
- 振動しやすい形や周波数を調べる。
- Webページの重要度を求める一部の方法。

などに使われます。

固有値を求めるときは、

```text
det(A-λI)=0
```

を解きます。`det`は行列式を求める記号です。式の導出を暗記するより、固有値は「その固有方向を何倍するか」と理解してください。

## 14 数列――規則に従って並ぶ数

順番に並んだ数を数列と呼びます。

```text
1, 3, 5, 7, 9, ...
```

各数を項と呼び、最初から`n`番目の項を`aₙ`と書きます。

### 一般項

上の数列は、`n`番目を、

```text
aₙ = 2n-1
```

と一つの式で表せます。この式を一般項と呼びます。

### 漸化式

前の項から次の項を決める書き方もあります。

```text
a₁=1
aₙ₊₁=aₙ+2
```

これを漸化式と呼びます。プログラムの繰返し処理に近い書き方です。

## 15 等差数列――同じ数を足し続ける

```text
3, 7, 11, 15, ...
```

隣どうしの差は常に4です。このような数列を等差数列と呼びます。

- 最初の項`a=3`
- 公差`d=4`

なら、`n`番目の項は、

```text
aₙ = a + (n-1)d
```

です。最初の項から、4を`n-1`回足すからです。

最初から`n`番目までの和は、

```text
Sₙ = n(a₁+aₙ)÷2
```

です。先頭と末尾、二番目と末尾の一つ前を組にすると、どの組も同じ和になることから導けます。

## 16 等比数列――同じ数を掛け続ける

```text
2, 6, 18, 54, ...
```

前の項を三倍すると次の項になります。このような数列を等比数列と呼び、掛ける数を公比と呼びます。

- 最初の項`a=2`
- 公比`r=3`

なら、

```text
aₙ = arⁿ⁻¹
```

です。

等比数列は、複利、指数的な増加、毎回一定割合で減る誤差などに現れます。

`r≠1`のとき、最初から`n`番目までの和は、

```text
Sₙ = a(1-rⁿ)÷(1-r)
```

です。式の符号を逆にして、`a(rⁿ-1)÷(r-1)`と書いても同じです。

## 17 フィボナッチ数列――前の二項を足す

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

最初の二項以外は、直前の二項を足します。

```text
F₀=0
F₁=1
Fₙ=Fₙ₋₁+Fₙ₋₂
```

再帰処理の教材としてよく登場します。定義をそのまま再帰プログラムにすると、同じ値を何度も計算して遅くなります。計算済みの値を保存するメモ化や、前から順に一度ずつ計算する動的計画法を使うと効率化できます。

## 18 三角関数――角度と辺の長さを結ぶ

直角三角形を考えます。注目する角を`θ`とします。`θ`はシータと読み、角度を表す文字としてよく使います。

- 斜辺：直角の向かい側にある最も長い辺。
- 対辺：`θ`の向かい側の辺。
- 隣辺：`θ`に接する辺のうち、斜辺でない方。

```text
sin θ = 対辺 ÷ 斜辺
cos θ = 隣辺 ÷ 斜辺
tan θ = 対辺 ÷ 隣辺
```

`sin`はサイン、`cos`はコサイン、`tan`はタンジェントと読みます。

### なぜITで使うのか

- 画面上で物体を回転する。
- 音や電波の周期的な波を表す。
- ロボットの腕の先端位置を求める。
- 三次元CGの光と面の角度を計算する。

角度には度数法と弧度法があります。

```text
180度 = πラジアン
360度 = 2πラジアン
```

微分やプログラムの数学関数は、ラジアンを使うことが多いので、単位を確認します。

## 19 恒等式と方程式を区別する

次の式は、どの`θ`でも成り立ちます。

```text
sin²θ + cos²θ = 1
```

このように、変数へ入れられるすべての値で成り立つ式を恒等式と呼びます。

一方、

```text
2x+1=7
```

は`x=3`のときだけ成り立つ方程式です。

「いつでも成り立つ関係」なのか、「成り立つ値を探す問題」なのかを区別します。

## 20 解析的に解くことと、数値的に解くこと

`2x+1=7`なら、式を変形して`x=3`と正確に求められます。このように、有限の記号操作で厳密な形の答えを得ることを、ここでは解析的に解くと呼びます。

ところが、現実の式には、きれいな形で解けないものや、解けても計算が非常に重いものがあります。

その場合、コンピュータで少しずつ答えへ近づく数値解法を使います。

```text
厳密解：正確な記号や式で表した答え
数値解：小数などで得た近似的な答え
```

近似は「でたらめ」ではありません。誤差を評価し、必要な精度を満たした答えです。

## 21 補間――分かっている点の間を推定する

時刻0秒で温度10℃、時刻2秒で温度18℃だったとします。1秒時点を測り忘れました。

二点を直線で結ぶと仮定すると、ちょうど中間なので14℃と推定できます。

これを線形補間と呼びます。

二点`(x₀,y₀)`と`(x₁,y₁)`の間で、`x`に対応する値は、

```text
y = y₀ + (y₁-y₀) × (x-x₀) ÷ (x₁-x₀)
```

です。

式を言葉にすると、

1. 全体の横幅に対し、どこまで進んだかという割合を求める。
2. 縦の変化量へその割合を掛ける。
3. 最初の高さへ足す。

です。

### 補間と外挿

- 補間：観測した点の間を推定する。
- 外挿：観測範囲の外を推定する。

外挿は、観測範囲の外でも同じ傾向が続くと仮定するため、一般に危険が大きくなります。

### 多項式補間とスプライン補間

多くの点を一つの高次多項式で通すと、点の間で大きく振動することがあります。区間ごとに低次の多項式を使い、境目を滑らかにつなぐ方法がスプライン補間です。

補間法は、滑らかさ、計算量、端での振舞い、データのノイズを考えて選びます。

## 22 常微分方程式――変化の速さから未来を求める

水槽の水量`y`が、一秒ごとに一定の速さ`3`で増えるなら、

```text
dy/dt = 3
```

と書けます。`dy/dt`は、「時間`t`が少し進んだとき、水量`y`がどれほど変わるか」という変化率です。

変化率と現在値の関係を表す式を微分方程式と呼びます。一つの**独立変数**についての通常の微分だけを含むものを常微分方程式と呼びます。未知の関数は従属変数であり、複数個あっても独立変数が一つなら連立常微分方程式になり得ます。複数の独立変数について偏微分を含むものは偏微分方程式です。

物体の運動、温度変化、人口、在庫、電気回路など、現実の変化を表すために使います。

## 23 オイラー法――今の傾きで、少し先へ進む

次の微分方程式を考えます。

```text
dy/dt = y
y(0)=1
```

「現在の値と同じ速さで増える」という意味です。

刻み幅を`h=0.1`とします。現在の傾きに刻み幅を掛け、現在値へ足します。

```text
次の値 = 現在値 + 刻み幅 × 現在の傾き
```

最初は`t=0, y=1`なので、傾きも1です。

```text
y(0.1) ≈ 1 + 0.1×1 = 1.1
```

次は、`y=1.1`なので傾きも1.1です。

```text
y(0.2) ≈ 1.1 + 0.1×1.1 = 1.21
```

これがオイラー法です。

### 刻み幅の影響

刻み幅を小さくすると、普通は曲線を細かく追えて誤差が減ります。しかし、計算回数が増え、丸め誤差も蓄積します。

また、急激に変化する問題や不安定な問題では、単純なオイラー法が大きく外れることがあります。改良オイラー法やルンゲ・クッタ法など、より精度や安定性の高い方法を使います。

## 24 数値積分を「面積の足し算」として復習する

曲線`y=f(x)`の下の面積を求めたいとします。積分記号で、

```text
∫ₐᵇ f(x) dx
```

と書きます。

厳密な積分が難しいとき、区間を細く分け、簡単な図形の面積を足します。

## 25 台形則――曲線を直線で結ぶ

区間`[a,b]`の両端の高さを`f(a), f(b)`とします。二点を直線で結び、台形の面積にします。

```text
面積 ≈ (b-a) × {f(a)+f(b)} ÷ 2
```

区間を複数に分ける複合台形則では、各小区間の台形を足します。

曲線が大きく曲がる区間では、直線近似の誤差が大きくなります。

## 26 シンプソン法――三点を放物線で結ぶ

シンプソン法は、区間の左端、中央、右端の三点を通る二次式、つまり放物線で曲線を近似します。

区間の幅を`2h`とし、三点を`x₀,x₁,x₂`とすると、

```text
面積 ≈ h/3 × {f(x₀) + 4f(x₁) + f(x₂)}
```

です。

中央の高さへ4を掛けることが特徴です。

### 例：`f(x)=x²`を0から2まで積分する

```text
x₀=0, x₁=1, x₂=2, h=1
f(0)=0, f(1)=1, f(2)=4
```

したがって、

```text
1/3 × (0 + 4×1 + 4)
= 8/3
```

です。二次式に対しては、この例では厳密な値と一致します。

複合シンプソン法では、小区間の個数を偶数にする必要があります。適用条件を確認してください。

## 27 誤差の次数――刻みを半分にしたら、どれほど良くなるか

数値解法には、刻み幅`h`を小さくしたとき、誤差がどの速さで減るかという性質があります。

誤差がだいたい`h`に比例する方法なら、`h`を半分にすると誤差は約半分です。誤差が`h²`に比例する方法なら、`h`を半分にすると誤差は約四分の一です。

これを収束次数で表します。

ただし、理論どおりになるのは、問題が必要な滑らかさを持ち、丸め誤差が支配的でなく、十分細かい範囲に入った場合です。

## 28 条件数――入力の小さな誤差が答えへ何倍響くか

どれほど優れた計算法でも、問題そのものが誤差に非常に敏感なら、正確な答えを得にくくなります。

入力の相対誤差が、出力の相対誤差へおよそ何倍に増幅され得るかを表す指標を条件数と呼びます。

- 条件数が1に近い：比較的安定。
- 条件数が非常に大きい：小さな入力誤差が大きく増幅される恐れ。

「問題の悪条件性」と「計算法の不安定性」は分けて考えます。

- 悪条件：問題自体が敏感。
- 数値的不安定：計算法が不要に誤差を増やす。

測定値に誤差がある現実では、答えの桁を必要以上に表示しても、正確になったことにはなりません。

## 29 数式処理――数値ではなく記号のまま計算する

電卓は、`2+3`を5にします。数式処理システムは、文字を含む式を記号のまま変形できます。

```text
(x+1)² → x²+2x+1
x²-1 → (x-1)(x+1)
d/dx (x³) → 3x²
∫ 2x dx → x² + C
```

このような処理を記号計算、または数式処理と呼びます。

用途は、

- 式の展開、因数分解、簡単化。
- 方程式を記号で解く。
- 微分・積分。
- 行列の記号計算。
- 数式の性質を調べる。

です。

### 数式処理の注意

式変形には、変数の範囲や分母が0でないことなどの条件があります。

例えば、

```text
x/x = 1
```

は`x≠0`のときだけです。`x=0`なら、左辺は0で割るため定義できません。

コンピュータが返した簡単な式だけでなく、その式が成り立つ条件も確認します。

また、数式処理で得た厳密な式が巨大になり、数値計算より扱いにくい場合もあります。記号計算と数値計算を目的に応じて使い分けます。

## 30 数値解析の安全確認表

計算結果を受け取ったら、次を確認します。

1. 入力の単位は一致しているか。
2. 適用した公式や解法の前提を満たすか。
3. 刻み幅や停止条件は十分か。
4. 刻み幅を半分にしても、結果がほぼ変わらないか。
5. 別の解法でも近い値になるか。
6. 元の式へ代入し、残差が小さいか。
7. 答えの符号や大きさは、現実的か。
8. オーバフロー、アンダフロー、丸め、桁落ちはないか。
9. 入力誤差に対して問題が敏感でないか。
10. 必要以上の桁を「正確」として報告していないか。

残差とは、近似解を元の式へ入れたときの食い違いです。残差が小さくても、悪条件問題では解そのものの誤差が大きいことがあるため、条件数も考えます。

## 内積と固有値の条件を補う

内積は`a・b=|a||b|cosθ`なので、方向だけでなく両ベクトルの長さにも依存します。方向の一致度だけを比較するなら、両方が零ベクトルでない条件で、`(a・b)/(|a||b|)`というコサイン類似度を使います。

固有ベクトルの定義`Av=λv`では、`v≠0`が必須です。`I`は対角成分が1、他が0の**単位行列**で、固有値は`det(A-λI)=0`から求めます。例えば、

```text
A = [2 0]
    [0 3]

det(A-λI) = (2-λ)(3-λ) = 0
```

よって固有値は2と3です。λ=2では`(A-2I)v=0`から`v=(1,0)`の定数倍、λ=3では`v=(0,1)`の定数倍が固有ベクトルです。
