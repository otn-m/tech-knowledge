# 第1章17 線形代数と数値解析――たくさんの数と、解けない式を扱う道具

## 複数の量を順序付きで表す

平面上の座標において、`(3, 2)` と `(2, 3)` は全く同じ「2」と「3」という2つの数字から構成されていますが、幾何学的な位置としては完全に異なる地点を指し示します。複数の数値を同時に取り扱う際には、個々の数値の大きさだけでなく、並び順や「行と列」の対応関係そのものに決定的な意味が宿るわけです。

この順序構造を厳格に保持したまま演算規則を定式化することで、空間内の回転や移動、数千元に及ぶ連立方程式の求解、さらには複雑なデータ変換を一括して代数的に処理できるようになります。

ただし、どれほど数式の形式を綺麗に整えたとしても、逆変換が存在しない「情報を不可逆につぶしてしまう変換」や、入力データのわずかな測定誤差が計算結果を桁外れに狂わせてしまう「悪条件な問題」が常に潜んでいます。計算の代数規則を正しく把握したうえで、記号的に厳密に解ける部分と、コンピュータで近似的に追い詰める数値解析の領域を明確に見極めなければなりません。

### 1 スカラー――1個だけの数

気温が25℃、室内の人数が40人、サーバの応答時間が2.5秒といったように、ただ1つの数値だけで完全に大きさを指定できる物理量を「スカラー（scalar）」と呼びます。

```text
温度 = 25
人数 = 40
時間 = 2.5
```

スカラーという語は、特別な高等数学の計算法を指すものではありません。後述するベクトルや行列のように「複数の数が束になった量」と対比させ、単一の独立した数値として扱っていることを明確に区別するための呼び名です。

### 2 ベクトル――順番のある数の列

ある地点の位置を、東西方向の座標 `x = 3`、南北方向の座標 `y = 2` の組として表現してみます。

```text
(3, 2)
```

このように、順序付けられた複数の数値の並びが「ベクトル（vector）」です。並び順は極めて重要であり、順序を入れ替えた `(2, 3)` は全く異なる場所を表すことになります。

情報科学においてベクトルは、単なる幾何学的な位置や速度を表すだけに留まりません。

- 物理的な速度：東向きに3 m/s、北向きに2 m/sの合成速度。
- 購買ログの数量：鉛筆3本、消しゴム2個という購買行動。
- ディジタル画像の色情報：赤（R）が200、緑（G）が100、青（B）が50という画素値。
- 利用者の属性特徴量：年齢、年収、月間利用回数を並べた特徴ベクトル。

このように、対象が持つ複数の属性値を1本のベクトルとしてモデル化する手法が、現代のデータ処理やAI技術の出発点となります。

#### ベクトルの加算

東へ3、北へ2進んだ後、引き続いて東へ1、北へ4進む移動を考えてみましょう。

```text
(3, 2) + (1, 4) = (3 + 1, 2 + 4) = (4, 6)
```

ベクトルの足し算は、互いに対応する同じ位置の成分（要素）同士を単純に足し合わせるだけで計算できます。

#### スカラー倍

ベクトル全体に対して単一の数（スカラー）を掛け合わせる演算がスカラー倍です。

```text
2 × (3, 2) = (2 × 3, 2 × 2) = (6, 4)
```

幾何学的には、ベクトルの向いている方向を保ったまま、長さ（大きさ）だけを2倍に引き伸ばす操作に相当します。もし `-1` のような負のスカラーを掛けた場合は、大きさはそのままに向きだけが真逆へと反転する寸法です。

### 3 内積――2つの向きの近さと相関を測る

2つのベクトルの幾何学的・代数学的な関係性を、ただ1つのスカラー値へと集約する演算が「内積（dot product / inner product）」です。

2次元ベクトル `a = (a₁, a₂)` と `b = (b₁, b₂)` の内積は、対応する成分同士の積の総和として定義されます。

```text
a · b = a₁b₁ + a₂b₂
```

たとえば `(3, 2)` と `(4, 1)` の内積を計算してみましょう。

```text
(3, 2) · (4, 1) = 3×4 + 2×1 = 12 + 2 = 14
```

内積には「2つのベクトルがどれほど同じ向きを揃って向いているか」を数値化する重大な幾何学的意味が存在します。ベクトルのなす角を `θ` と置くとき、内積は次の関係式を満たすからです。

```text
a · b = |a| |b| cos θ
```

- なす角が鋭角（概ね同方向）：内積は正の値をとる。
- 直角（互いに直交）：`cos 90° = 0` であるため、内積は厳密に 0 となる。
- 鈍角（逆向きに近い）：内積は負の値をとる。

検索エンジンや機械学習の推薦システムでは、何千単語もの出現頻度を巨大な多次元ベクトルとして表現し、文書同士の内積を計算することで関連性の強さを判定します。ただし内積の値は、ベクトルの向きの一致度だけでなく、各ベクトルの長さ（ノルム `|a|` や `|b|`）そのものにも左右されてしまいます。

そこで、両ベクトルがゼロベクトルでない条件下において、長さの影響を相殺して純粋に向きの類似度だけを比較する指標が「コサイン類似度」です。

```text
コサイン類似度 = (a · b) ÷ (|a| |b|) = cos θ
```

この値は `-1` から `+1` までの範囲に正規化されるため、文書の文字数やログの絶対量に惑わされることなく、内容の類似性だけを公平に評価できるわけです。

## 行と列で計算をまとめる

### 4 行列――数を格子状に並べた構造

数値を長方形の格子状に縦横に並べた数学的対象を「行列（matrix）」と呼びます。

```text
A = [1  2  3]
    [4  5  6]
```

水平方向の数の並びを「行（row）」、垂直方向の並びを「列（column）」と呼びます。上記の行列 `A` は、横に2つの行、縦に3つの列を持つため「2行3列（2×3）の行列」と表現する決まりです。

行列は、複数の観測データを整理した一覧表として扱われるだけでなく、ある空間のベクトルを別の空間のベクトルへと写し取る幾何学的変換の規則そのものを記述する道具として絶大な力を発揮します。

### 5 転置行列――行と列を入れ替える操作

行と列の配置を入れ替える操作も頻繁に用いられる重要な手法です。行列 `A` の行と列を反転させて得られる行列を「転置行列（transposed matrix）」と呼び、記号 `Aᵀ` で表記します。

```text
A  = [1  2  3]
     [4  5  6]

Aᵀ = [1  4]
     [2  5]
     [3  6]
```

元の2行3列の行列が、転置によって3行2列の行列へと姿を変えました。転置操作は、縦に並んだ列ベクトルを横向きの行ベクトルに寝かせたり、行列の積を用いて多数のデータの内積を一括計算したりする場面で不可欠な役割を担います。

### 6 行列の加算とスカラー倍

行列同士の足し算は、行数と列数が完全に一致している（サイズが等しい）行列同士においてのみ定義されます。計算手続きは直感的であり、全く同じ位置にある要素同士を個別に足し合わせるだけです。

```text
[1 2] + [5 6] = [1+5  2+6] = [6   8]
[3 4]   [7 8]   [3+7  4+8]   [10 12]
```

スカラー倍においても同様に、行列に含まれるすべての要素に対して一律にそのスカラー値を掛け合わせます。

```text
2 × [1 2] = [2×1  2×2] = [2 4]
    [3 4]   [2×3  2×4]   [6 8]
```

### 7 行列とベクトルの積――連立する関係を一度に変換する

行列の真価が最も鮮やかに現れるのが、ベクトルや別の行列との掛け算です。

```text
[2 1] [3] = [ 2×3 + 1×4 ] = [ 6 + 4 ] = [10]
[0 5] [4]   [ 0×3 + 5×4 ]   [ 0 + 20]   [20]
```

左側の行列の各「行」を取り出し、右側の縦ベクトルの各要素と内積をとるように掛け合わせて足し上げます。この計算は、次の2本の連立方程式に対して、未知数 `x = 3, y = 4` を同時に代入して計算結果を得ている構造そのものです。

```text
2x + 1y = 10
0x + 5y = 20
```

#### 積が成立するためのサイズ条件

2つの行列の掛け算 `A × B` が成立するためには、左側の行列 `A` の「列数」と、右側の行列 `B` の「行数」が厳密に一致していなければなりません。

```text
(m 行 n 列) × (n 行 p 列) → (m 行 p 列)
```

通常の数値の掛け算であれば `2 × 3 = 3 × 2 = 6` のように順番を自由に入れ替えられますが、行列の積においては一般に交換法則が成り立ちません（非可換性）。`AB` が計算できても `BA` はサイズ不一致で計算すらできないケースが日常茶飯事であり、仮に両方が計算できる正方行列同士であっても、通常は `AB ≠ BA` となります。行列の積とは「変換を適用する順番」を表しているため、順番を勝手に入れ替えてはならないわけです。

### 8 単位行列――掛けても相手を変えない恒等元

通常の数の世界において、数字の「1」はどんな数に掛けても相手の値を変えません。

```text
1 × 7 = 7
```

行列の世界において、この「1」とまったく同じ役割を果たす特別な正方行列が「単位行列（identity matrix）」であり、記号 `I` や `E` で表されます。主対角線上の要素がすべて 1 であり、それ以外の要素がすべて 0 である行列です。

```text
I = [1 0]
    [0 1]
```

任意の2次元ベクトルにこの単位行列を左から掛けて確認してみましょう。

```text
[1 0] [x] = [1·x + 0·y] = [x]
[0 1] [y]   [0·x + 1·y]   [y]
```

元のベクトルが寸分違わずそのまま出力される寸法です。

### 9 逆行列と行列式――変換を元へ巻き戻す

ある数に `2` を掛けた効果は、その逆数である `1/2` を掛けることで完全に元の状態へ復元できます。

```text
2 × (1/2) = 1
```

正方行列 `A` に対しても、掛け合わせることで結果が単位行列 `I` になるような「逆の変換」を担う行列を「逆行列（inverse matrix）」と呼び、記号 `A⁻¹` で表記する決まりです。

```text
A A⁻¹ = A⁻¹ A = I
```

ただし、すべての行列に逆行列が存在するわけではありません。たとえば、2次元の平面全体をただ1本の直線の上へペシャンコに押しつぶしてしまう変換行列を考えてみます。ひとたび直線上に潰されてしまった点は、元々平面のどこにあった点なのかという情報が完全に失われてしまうため、逆向きに辿って元の一意な位置へ復元することは不可能です。

2行2列の正方行列について、逆行列が存在するかどうかを判定する指標が「行列式（determinant）」です。

```text
A = [a b]
    [c d]
```

この行列 `A` に対する行列式は `det(A) = ad - bc` で定義され、逆行列は次の公式で与えられます。

```text
A⁻¹ = 1/(ad - bc) × [ d -b]
                    [-c  a]
```

もし分母の `ad - bc` が 0 であれば、ゼロ除算となるため逆行列は存在しません。幾何学的には、行列式は変換によって空間の体積や面積が何倍に拡大されるかを表すスケール比率であり、行列式が 0 になることは「空間が潰れて面積がゼロになった」ことを意味するわけです。

なお、数十元〜数千元規模の連立方程式をコンピュータで解く実務において、逆行列そのものを明示的に求めるアプローチは推奨されません。計算量が莫大になるだけでなく数値誤差が蓄積しやすいため、後述する消去法によって直接解を求めるのが計算科学の鉄則です。

### 10 テンソル――多次元に広がる数の配列

現代の大規模データ処理やディープラーニングでは、2次元の行と列だけでは表現しきれない多次元データが登場する状況に直面します。数の並ぶ「方向の次元数（階数）」に応じて、概念を次のように体系的に整理することが可能です。

- スカラー（0階テンソル）：方向を持たない、ただ1つの数値。
- ベクトル（1階テンソル）：1つの軸に沿って直線状に並ぶ数の列。
- 行列（2階テンソル）：行と列という2つの直交軸に沿って平面格子状に並ぶ数。
- テンソル（3階以上の高階テンソル）：3方向以上の空間軸に沿って並ぶ多次元配列。

たとえば、1枚のカラー画像データは「縦の画素数（高さ）× 横の画素数（幅）× RGB色空間（3色）」という3つの方向に数値が整列した3階テンソルとして自然にモデル化されます。さらに複数枚の画像をミニバッチとして束ねれば、「画像枚数 × 高さ × 幅 × チャンネル数」という4階テンソルの構造をとる寸法です。

## 方程式と変換の性質を調べる

### 11 連立方程式を行列の枠組みで捉える

次の中学校で習う2元1次連立方程式を題材に取り上げてみましょう。

```text
2x + 1y = 5
1x - 1y = 1
```

未知数 `x, y` の係数と、右辺の定数項を行列とベクトルに分離して記述する形式をとります。

```text
[2  1] [x] = [5]
[1 -1] [y]   [1]
```

係数行列を `A`、未知数ベクトルを `x`、右辺定数ベクトルを `b` と命名すれば、連立方程式全体が極めて簡潔な1行の等式へと抽象化されるわけです。

```text
Ax = b
```

もし係数行列 `A` に逆行列 `A⁻¹` が存在するならば、両辺の左から `A⁻¹` を掛けることで、数学的には一撃で解が求まることになります。

```text
A⁻¹Ax = A⁻¹b
Ix = A⁻¹b
x = A⁻¹b
```

どれほど未知数の数が増大して巨大な方程式になろうとも、「Ax = b」という統一的な幾何学的・代数的な枠組みの中で解の存在条件や性質を議論できる点が、線形代数学の最大の強みです。

### 12 ガウスの消去法――系統的に未知数を消去する

先ほどの連立方程式を手作業で解く際、中学校では加減法を用いました。

```text
2x + y = 5   …(1)
 x - y = 1   …(2)
```

式(2)を2倍して `2x - 2y = 2` を作り、これを式(1)から差し引くことで未知数 `x` を消去して `3y = 3`、すなわち `y = 1` を導きます。得られた `y = 1` を元の式へ代入し戻すことで `x = 2` を確定させる解法です。

この代数的な消去手続きを、行列の行操作としてアルゴリズム化した手法が「ガウスの消去法（Gaussian elimination）」です。

#### 拡大係数行列と行基本変形

未知数の文字 `x, y` を省き、係数と右辺定数だけを横に連結した「拡大係数行列」を用意します。

```text
[2  1 | 5]
[1 -1 | 1]
```

方程式の解を一切変えずに実行できる変形操作（行基本変形）は、次の3種類のみです。

1. 任意の2つの行を丸ごと入れ替える。
2. ある行の全要素を、0以外のスカラー倍する。
3. ある行の定数倍を、別の行に足し合わせる（または引き算する）。

これらの基本変形を順次適用して、対角線より下の要素をすべて 0 に整えた上三角行列（階段状の形）を作り出す工程を「前進消去」と呼びます。階段状になった後、最下段の式から順に未知数の値を確定させながら上へ上へと遡って代入していく工程が「後退代入」です。

#### ピボット選択と数値的安定性

前進消去において、消去の基準となる対角要素を「ピボット（pivot）」と呼びます。ピボットの値で他の行を除算しながら消去を進めるため、ピボットが 0 である場合は計算が成立しません。

また、ピボットが 0 でなくとも絶対値が極端に小さな微小値であった場合、その値で除算することで丸め誤差が劇的に拡大し、後続の計算結果を完全に破壊してしまう危険性があるわけです。

そこで、消去を行う列の中で絶対値が最も大きな要素を持つ行を探し出し、行の入れ替えを行ってから消去を実行する「部分ピボット選択付きガウス消去法」が、数値解析の実務では必須の標準技術として採用されています。数学的に同一の解を与える手順であっても、計算順序の工夫ひとつで数値的な安定性が劇的に変化する好例です。

### 13 固有値と固有ベクトル――変換の主軸を見抜く

行列 `A` は、空間内のベクトルを別のベクトルへと移す変換を担います。一般には、行列を掛けられたベクトルは元の向きから回転し、長さも変化するのが普通です。

ところが、無数にあるベクトルの中には、行列 `A` を掛けられても「まったく向きが変わらず、ただ長さが定数倍されるだけ」という極めて特別な方向を向いた非零ベクトル `v` が存在します。

```text
Av = λv   （v ≠ 0）
```

このとき、向きを変えない特別なベクトル `v` を行列 `A` の「固有ベクトル（eigenvector）」、その引き伸ばし倍率を表すスカラー `λ` を「固有値（eigenvalue）」と呼ぶわけです。

#### 簡単な対角行列での例証

```text
A = [2 0]
    [0 3]
```

横向きの単位ベクトル `v = (1, 0)` に対して行列 `A` を掛けてみます。

```text
Av = [2 0] [1] = [2] = 2 × [1] = 2v
     [0 3] [0]   [0]       [0]
```

向きは真横を向いたまま、長さだけがちょうど2倍に伸長されました。したがって `(1, 0)` は固有値 2 に対応する固有ベクトルです。同様に縦向きのベクトル `(0, 1)` に掛けると `(0, 3) = 3 × (0, 1)` となり、固有値 3 に対応する固有ベクトルとなります。

固有値を数学的に算出するためには、方程式 `(A - λI)v = 0` が非零解を持つ条件、すなわち行列式が 0 になる特性方程式を解く必要があります。

```text
det(A - λI) = 0
```

先ほどの対角行列であれば `(2 - λ)(3 - λ) = 0` となり、固有値が 2 と 3 であることが直ちに判明するわけです。

固有値と固有ベクトルを見つけ出すことは、その変換が持つ主たる拡大・縮小の軸を暴き出すことに他なりません。この理論は、マルコフ連鎖の定常分布の解析、主成分分析における分散最大の主軸探索、物理構造物の共振周波数解析、Googleの原点となったWebページの重要度判定アルゴリズム（PageRank）に至るまで、情報工学のあらゆる中核領域を支え続けています。

## 規則的な数値の変化を捉える

### 14 数列――規則に従って並ぶ数の系列

行列による一括変換と並び、アルゴリズムの基礎となるのが、前後の依存関係に従って規則的に生成される数の並び「数列（sequence）」です。

```text
1, 3, 5, 7, 9, ...
```

並んだ各数値を「項」と呼び、先頭から `n` 番目の項を一般に `aₙ` と表記します。数列の振る舞いを記述するアプローチには主に2つの表現形式があります。

- 一般項：任意の番号 `n` を代入するだけで、その項の値が一発で求まる陽的な数式（例：`aₙ = 2n - 1`）。
- 漸化式：前の項の値から次の項の値を導き出す規則を定めた再帰的な関係式（例：`a₁ = 1, aₙ₊₁ = aₙ + 2`）。

漸化式は、プログラミング言語におけるループ処理や再帰関数と論理的に直結した思考法です。

### 15 等差数列と等比数列

#### 等差数列（隣との差が一定）

```text
3, 7, 11, 15, ...
```

隣り合う項の差が常に一定値 `d`（公差）である数列を「等差数列」と呼びます。初項を `a`、公差を `d` と置くとき、一般項と初項から第 `n` 項までの総和 `Sₙ` は次の数式で表される関係です。

```text
一般項: aₙ = a + (n - 1)d
総和: Sₙ = n(a₁ + aₙ) ÷ 2
```

和の公式は、先頭と末尾のペア `(a₁ + aₙ)` を作るとどの組も全く同じ値になるという、ガウスの少年時代の有名な逸話に基づく美しい対称性から導出されます。

#### 等比数列（隣との比が一定）

```text
2, 6, 18, 54, ...
```

前の項に常に一定の数 `r`（公比）を掛け合わせることで次項が生成される数列を「等比数列」と呼びます。初項 `a`、公比 `r`（ただし `r ≠ 1`）における一般項と総和は次の通りです。

```text
一般項: aₙ = a rⁿ⁻¹
総和: Sₙ = a(1 - rⁿ) ÷ (1 - r)
```

等比数列は、金融システムの複利計算、指数関数的なトラフィックの爆発的増加、二分探索における探索空間の半減プロセスなど、計算機科学の計算量評価に絶えず顔を出します。

### 16 フィボナッチ数列と計算効率化の知恵

```text
0, 1, 1, 2, 3, 5, 8, 13, 21, ...
```

直前の2つの項を足し合わせることで次項を決定する数列が「フィボナッチ数列」です。

```text
F₀ = 0
F₁ = 1
Fₙ = Fₙ₋₁ + Fₙ₋₂   （n ≥ 2）
```

フィボナッチ数列の漸化式をそのまま愚直な再帰関数としてプログラミングすると、計算量は `O(2ⁿ)` という壊滅的な指数爆発を引き起こします。同じ引数に対する計算が幾何級数的に重複して呼び出されるためです。

そこで、一度計算した結果をテーブルに保存して再利用する「メモ化（memoization）」や、配列の先頭から順に一度ずつ足し上げていく「動的計画法（Dynamic Programming）」を適用することで、計算量を `O(n)` の線形時間へと劇的に圧縮できます。数列の漸化式をアルゴリズムへと落とし込む際には、数学的な定義の美しさと計算資源のリアリズムを常に天秤にかけなければなりません。

## 幾何と角度を結ぶ三角関数

### 17 三角関数――回転と周期運動を操る道具

直角三角形において、直角以外の1つの鋭角を `θ`（シータ）と置きます。直角の向かい側にある最長の辺を「斜辺」、角 `θ` の向かい側にある辺を「対辺」、残る隣の辺を「隣辺」と定義するとき、3本の辺の比率は角度 `θ` のみによって完全に一意に定まります。

```text
sin θ（サイン / 正弦）   = 対辺 ÷ 斜辺
cos θ（コサイン / 余弦） = 隣辺 ÷ 斜辺
tan θ（タンジェント / 正接） = 対辺 ÷ 隣辺
```

ITエンジニアが三角関数を自在に操るべき理由は、ゲームやCGプログラミングにおける3次元物体の回転行列の構築、音声や電波といった周期波形の合成・周波数解析、ロボットアームの逆運動学計算など、物理世界とコンピュータを繋ぐ座標変換の基盤となるからです。

数学やプログラミング言語の標準ライブラリ（`math.sin` など）では、度数法（360度）に代わり、弧の長さで角度を表す「弧度法（ラジアン: radian）」が標準として用いられます。

```text
180度 = π ラジアン
360度 = 2π ラジアン
```

また、三平方の定理（ピタゴラスの定理）を三角関数で表現し直した次の関係式は、角度 `θ` がどんな値であっても常に成立する極めて重要な「恒等式」です。

```text
sin²θ + cos²θ = 1
```

特定の値を探す方程式と、いかなる入力値でも恒常的に成立する恒等式を正しく峻別して数式を読み解く姿勢が不可欠です。

## 観測と変化から数値解を導く

### 18 解析解と数値解――厳密に解けない現実に立ち向かう

`2x + 1 = 7` という代数方程式であれば、式の移項と割り算という有限回の記号操作によって `x = 3` という真の解を寸分違わず導き出せます。このように、数式変形によって厳密な閉じた式として得られる解を「解析解（analytical solution）」と呼びます。

しかし、実世界の現象を表す複雑な非線形方程式や多元連立方程式の多くは、人間の手による代数的な式変形では解析解を導出できません。解けたとしても計算コストが非現実的な規模に膨れ上がります。

そこで、コンピュータの圧倒的な反復計算能力を駆使して、真の解に十分に近い近似値を段階的に絞り込んでいくアプローチが「数値解析（numerical analysis）」であり、得られた近似解を「数値解（numerical solution）」と呼ぶわけです。数値解における近似は、生じる誤差の上限を数学的に保証し、実用上必要な精度を工学的に担保する厳密な計算体系といえます。

### 19 データ補間――離散的な観測値の隙間を埋める

ある温度センサのログにおいて、時刻0秒で10℃、時刻2秒で18℃という飛び飛びの測定値が得られたとします。測定の空白となっている「時刻1秒」における温度を合理的に推定したい場面を考えてみましょう。

2つの観測点の間を直線で結び、時間経過に比例して温度が変化したと仮定すれば、中点である1秒時点の温度は `14℃` と推定できます。これが最も素朴な「線形補間（linear interpolation）」です。

```text
y = y₀ + (y₁ - y₀) × (x - x₀) ÷ (x₁ - x₀)
```

この計算は、全体の横幅に対する進行比率を求め、その比率を縦の変化量に掛け合わせて起点に足すという3ステップで構成されます。

観測データの既知の範囲の内側を埋める処理を「補間（interpolation）」と呼ぶのに対し、観測範囲の外側の未来や過去を予測する処理が「外挿（extrapolation）」です。外挿は観測範囲外でも同一の法則が維持されているという強い仮定に依存するため、予測が大きく外れる危険性を常に孕む点に注意が必要です。

多数の観測点を滑らかに繋ぐ手法として、高次の単一多項式で全点を通そうとすると、端点付近で不自然な激しい波打ち振動が発生してしまいます（ルンゲ現象）。そのため、隣接する小区間ごとに低次（通常は3次）の多項式を割り当て、接続部分の傾きと曲率が滑らかに連続するように繋ぎ合わせる「スプライン補間（spline interpolation）」が、CADやコンピュータグラフィックスの曲線描画で標準的に利用されています。

### 20 常微分方程式とオイラー法

未来の物理状態を予測する強力な手段が、変化率と現在状態の関係を記述した「微分方程式（differential equation）」です。含まれる未知関数の独立変数が時間 `t` など単一の変数のみであるものを「常微分方程式（ODE: Ordinary Differential Equation）」と呼びます。

たとえば、現在の値 `y` に比例して増加速度が増していく次の方程式を考えます。

```text
dy/dt = y
初期条件: y(0) = 1
```

これをコンピュータ上で数値的に解く最も基本的なアルゴリズムが「オイラー法（Euler's method）」です。時間の刻み幅を微小な値 `h = 0.1` と設定し、「次の値 ≈ 現在値 + 刻み幅 × 現在の傾き」という前進差分近似をステップごとに繰り返します。

```text
ステップ0 (t=0): y(0) = 1, 傾き dy/dt = 1
ステップ1 (t=0.1): y(0.1) ≈ 1 + 0.1 × 1 = 1.1, 傾き dy/dt = 1.1
ステップ2 (t=0.2): y(0.2) ≈ 1.1 + 0.1 × 1.1 = 1.21
```

オイラー法は直感的ですが、刻み幅 `h` の1次に比例した打ち切り誤差が毎ステップ蓄積するため、長時間の予測では真の解から乖離しやすい欠点を抱えています。刻み幅をむやみに極小化すると今度は反復回数が増加して浮動小数点数の丸め誤差が蓄積するため、実務では各ステップの途中で複数の傾きを巧みにサンプリングして高精度と安定性を両立させた「ルンゲ・クッタ法（Runge-Kutta method）」が標準的に採用される構成です。

## 積分を幾何学的な和で近似する

### 21 数値積分の原理――台形則とシンプソン則

曲線 `y = f(x)` と x 軸で囲まれた領域の面積を求める定積分において、被積分関数の原始関数が初等関数で表せない場合、数値積分によって面積を近似計算します。

#### 台形則（曲線を直線で近似）

区間 `[a, b]` の両端の関数値 `f(a)` と `f(b)` を結ぶ直線で近似し、台形の面積公式を適用する手法です。

```text
面積 ≈ (b - a) × {f(a) + f(b)} ÷ 2
```

全区間を多数の小区間に細分化して台形の面積を足し上げる「複合台形則」を用いることで精度を高められますが、曲線の曲がりが急峻な領域では直線近似の隙間に起因する誤差が無視できなくなります。

#### シンプソン則（曲線を2次放物線で近似）

区間の両端 `x₀, x₂` と、そのちょうど中央の中点 `x₁` の合計3点を通る2次多項式（放物線）で曲線をフィッティングして面積を算出する高度な解法が「シンプソン則（Simpson's rule）」です。小区間の幅を `h` と置くとき、面積は次の重み付き平均公式で求められます。

```text
面積 ≈ (h / 3) × {f(x₀) + 4f(x₁) + f(x₂)}
```

中央のサンプリング点に対して「4」という大きな重みを配分している点が最大の特徴です。

例として、`f(x) = x²` を `x = 0` から `x = 2` まで積分してみましょう。区間幅 `2h = 2` より `h = 1`、3点は `x₀ = 0, x₁ = 1, x₂ = 2` となり、対応する高さは `f(0) = 0, f(1) = 1, f(2) = 4` です。

```text
面積 ≈ (1 / 3) × (0 + 4×1 + 4) = (1 / 3) × 8 = 8/3 ≈ 2.667
```

解析的に定積分を計算すると `[x³/3]₀² = 8/3 - 0 = 8/3` となり、シンプソン則の計算結果は厳密解と完全に一致します。シンプソン則は2次式のみならず3次多項式に対しても数学的に厳密な解を与える驚くべき性質を備えています。複合シンプソン則を適用する際には、全体の分割区間数が必ず偶数でなければならない点に注意を要するわけです。

## 計算の不確実性と安定性を診断する

### 22 収束次数と条件数――アルゴリズムの性能と問題自体の性質

数値計算の結果を評価する際には、「計算法自体の優秀さ」と「問題そのものが抱える困難さ」という2つの独立した視点を峻別しなければなりません。

#### 収束次数（アルゴリズム側の性能指標）

刻み幅 `h` を半分にしたとき、計算誤差がどれほどの速度で縮小するかを表す指標が「収束次数」です。

- 1次精度の解法：誤差が `O(h)` に比例するため、刻み幅を半分にすると誤差は約 `1/2` に減る（オイラー法など）。
- 2次精度の解法：誤差が `O(h²)` に比例するため、刻み幅を半分にすると誤差は約 `1/4` に激減する（台形則など）。
- 4次精度の解法：誤差が `O(h⁴)` に比例するため、刻み幅を半分にすると誤差は一気に `1/16` まで縮小する（古典的ルンゲ・クッタ法など）。

#### 条件数（問題側の過敏性指標）

一方で、どれほど高精度なアルゴリズムを用いても、解くべき対象の問題そのものが過敏であれば正しい解は得られません。入力データに含まれる微小な相対誤差が、最終的な解の相対誤差として最大何倍に増幅されて跳ね返ってくるかを示す指標が「条件数（condition number）」です。

- 条件数が 1 に近い（良条件問題）：入力の誤差がそのまま同等のスケールで出力に伝わるため、計算は極めて安定する。
- 条件数が極端に巨大（悪条件問題）：入力のわずか 0.1% の測定ノイズや丸め誤差が、出力結果において数百%〜数万%の致命的な誤差へと大爆発する。

連立方程式において係数行列の行ベクトル同士がほぼ平行に近い場合、幾何学的には2本の直線がほとんど重なり合っている状態を意味するため、直線の位置がわずかに揺れただけで交点の位置が空間上を激しく暴走します。これが悪条件問題の本質です。「問題自体の悪条件性」と「アルゴリズムの数値的不安定性」を混同せず、問題が過敏であるならば測定精度を高めるか問題の定式化自体を再設計しなければなりません。

### 23 記号計算（数式処理）と数値計算の相補性

電卓や通常の数値計算プログラムは、式の中の数値を即座に浮動小数点数へと変換して近似計算を行います。これに対して、文字変数を記号（シンボル）のまま保持し、代数的な展開や因数分解、記号微分・記号積分を正確に実行するシステムを「数式処理システム（CAS: Computer Algebra System）」と呼びます。

```text
代数展開: (x + 1)² → x² + 2x + 1
因数分解: x² - 1 → (x - 1)(x + 1)
記号微分: d/dx (x³) → 3x²
記号積分: ∫ 2x dx → x² + C
```

数式処理は丸め誤差を一切生じさせない強力な手法ですが、式変形が成り立つ前提条件（分母がゼロでないことや根号内が正であること）を人間が確認しなければなりません。また、複雑な偏微分方程式などでは記号計算の結果得られる数式が何万行にも及ぶ巨大な怪物となり、メモリを枯渇させる場合もあります。記号計算で解析的な見通しを立てたうえで、最終的な大規模シミュレーションは高速な数値計算に委ねるという両者の使い分けが肝要です。

### 24 数値解析の安全確認点検表

数値シミュレーションや最適化計算の結果を実務で採用する際には、次の点検項目をチェックリストとして確認する習慣が重要となります。

1. **物理単位の整合性**：入力データの単位系（メートル、秒、ラジアン等）に不一致や混在はないか。
2. **前提条件の充足**：適用したアルゴリズムが要求する数学的前提（行列の正則性、関数の連続性や滑らかさ）を満たしているか。
3. **刻み幅の感度分析**：刻み幅 `h` を半分にして再計算したとき、有効数字の範囲内で解が安定して一致するか。
4. **代替手法によるクロスチェック**：異なるアルゴリズム（例：オイラー法とルンゲ・クッタ法）で解いた結果が整合しているか。
5. **残差の検証**：得られた近似解をもとの方程式 `Ax = b` に代入したとき、残差 `|Ax - b|` が機械精度の範囲に収まっているか。
6. **物理的妥当性**：出力された数値の符号、オーダー（桁数）、物理的意味が常識的な現象の範囲に収まっているか。
7. **数値例外の非発生**：計算の途中でゼロ除算、アンダーフロー、オーバーフロー、非数（NaN）が発生していないか。
8. **問題の条件数評価**：係数行列の条件数が巨大化しておらず、入力ノイズに過敏な悪条件に陥っていないか。
9. **有効桁数の過大報告防止**：入力データの精度が3桁しかないにもかかわらず、計算機の出力をそのまま10桁も「正確な数値」として報告していないか。

残差が小さく見える場合であっても、悪条件問題においては真の解との誤差が依然として巨大なまま放置されているケースがあります。

`(3, 2)` と `(2, 3)` を順序によって峻別した素朴なベクトルの第一歩から、行列による一括変換、固有値による主軸の抽出、そして解けない微分方程式を近似的に追跡する数値解析の技法に至るまで、すべての計算は「形式的な代数構造の正しさ」と「物理・数値的なリアリズム」を両輪として初めて、現実世界を動かす確固たる工学的知恵となるわけです。
