# 第1章・第17話　線形代数と数値解析――たくさんの数と、解けない式を扱う道具

`(3,2)`と`(2,3)`は同じ二つの数からできていますが、座標としては別の地点です。
複数の量を扱うときは、個々の値に加えて、順序や行と列の対応にも意味があります。
この対応を保つことで、移動や変換、複数の方程式をまとめて計算できます。

ただし、式の形をそろえても、元へ戻せない変換や、入力誤差に敏感な問題はあります。
計算の規則を確かめたうえで、厳密に求める部分と近似する部分を区別します。

## 複数の量を順序付きで表す

### 1 スカラー――一個だけの数

温度が25℃、人数が40人、処理時間が2.5秒というように、1個の数だけで表せる量をスカラーと呼びます。

```text
温度 = 25
人数 = 40
時間 = 2.5
```
「スカラー」は特別な計算法の名前ではありません。
「1個の数として扱っている」と区別するための名前です。

### 2 ベクトル――順番のある数の列

ある地点を、横方向の位置`x=3`、縦方向の位置`y=2`で表します。

```text
(3, 2)
```
このような順番のある数の列をベクトルと呼びます。

順番には意味があります。
`(3,2)`と`(2,3)`は違う地点です。

ベクトルは、位置だけでなく、次のようなものを表せます。

- 速度：東に3、北に2。
- 商品の個数：鉛筆3本、消しゴム2個。
- 色：赤の強さ200、緑100、青50。
- 人の特徴：身長、体重、年齢。

#### ベクトルの足し算

東に3、北に2進んだ後、東に1、北に4進みます。

```text
(3,2) + (1,4) = (4,6)
```
同じ位置どうしを足します。

#### スカラー倍

ベクトルを1個の数で何倍かします。

```text
2 × (3,2) = (6,4)
```
向きは同じまま、長さが2倍になります。
負の数を掛ければ、向きが反対になります。

### 3 内積――二つの向きが、どれほど同じか

二つのベクトルの関係を一つの数で表す計算に、内積があります。
`a=(a₁,a₂)`と`b=(b₁,b₂)`なら、次のように計算します。

```text
a・b = a₁×b₁ + a₂×b₂
```
たとえば、同じ位置の成分を掛けて足すと、次のようになります。

```text
(3,2)・(4,1) = 3×4 + 2×1 = 14
```
内積には、2つの向きがどれほど同じ方向を向くかを測る意味があります。

- 同じ方向に近い：正で大きくなりやすい。
- 直角：0。
- 反対方向：負になる。

検索や機械学習では、文章や利用者の好みを長いベクトルにし、内積やコサイン類似度で似ている度合いを測ることがあります。

内積は`a・b=|a||b|cosθ`なので、方向だけでなく両ベクトルの長さにも依存します。
方向の一致度だけを比較するなら、両方が零ベクトルでない条件で、`(a・b)/(|a||b|)`というコサイン類似度を使います。

## 行と列で計算をまとめる

### 4 行列――数を長方形に並べた表

次のような数の表を行列と呼びます。

```text
A = [1  2  3]
    [4  5  6]
```
横の並びを行、縦の並びを列と呼びます。
この行列は2行3列です。

行列は、ただの表としてデータを保存することもあれば、ベクトルを別のベクトルに変える規則を表すこともあります。

### 5 転置行列――行と列を入れ替える

行と列に意味を持たせると、その向きを変える操作も必要になります。
行列`A`の行と列を入れ替えたものが**転置行列**で、`Aᵀ`と書きます。

```text
A  = [1  2  3]
     [4  5  6]

Aᵀ = [1  4]
     [2  5]
     [3  6]
```
2行3列が、3行2列になりました。

転置は、縦向きのベクトルを横向きにしたり、行列の積で内積をまとめて計算したりするときに使います。

### 6 行列の足し算とスカラー倍

同じ大きさの行列どうしは、同じ場所の数を足します。

```text
[1 2] + [5 6] = [6  8]
[3 4]   [7 8]   [10 12]
```
スカラー倍では、すべての要素に同じ数を掛けます。

```text
2 × [1 2] = [2 4]
    [3 4]   [6 8]
```
### 7 行列とベクトルの掛け算――複数の式を一度に計算する

行列で変換規則を表すと、複数の式を一度に計算できます。

```text
[2 1] [3] = [2×3 + 1×4] = [10]
[0 5] [4]   [0×3 + 5×4]   [20]
```
左の行列の各行と、右のベクトルの内積を求めています。

ここでは、次の2式に`x=3, y=4`を代入した結果をまとめています。

```text
2x + y
0x + 5y
```
#### 掛けられる大きさ

`m行n列`の行列と、`n行p列`の行列を掛けると、`m行p列`になります。

真ん中の`n`が一致する必要があります。

```text
(m×n) × (n×p) → (m×p)
```
数の掛け算では、`2×3`と`3×2`の値は同じです。
行列の掛け算は変換を適用する順序を表すため、数の掛け算と違い、一般には順番を入れ替えられません。
`AB`が計算できても`BA`が計算できない場合があり、両方計算できても値が違う場合があります。

### 8 単位行列――掛けても変えない行列

数の1は、何かに掛けても値を変えません。

```text
1×7=7
```
行列にも同じ役割のものがあります。
対角線に1、それ以外に0が並ぶ単位行列です。

```text
I = [1 0]
    [0 1]
```
どの2次元ベクトルに掛けても変わりません。

```text
[1 0][x] = [x]
[0 1][y]   [y]
```
### 9 逆行列――行列による変換を元へ戻す

数`2`を掛けた操作は、`1/2`を掛けると元に戻せます。

```text
2 × (1/2) = 1
```
行列`A`について、掛けると単位行列になる行列を逆行列と呼び、`A⁻¹`と書きます。

```text
A A⁻¹ = A⁻¹ A = I
```
ただし、逆行列はすべての行列に存在するわけではありません。
例えば、2次元の面全体を1本の線に押しつぶす変換は、どの元の点だったか分からなくなるため、完全には戻せません。

2行2列の行列を、次の形で表します。

```text
A = [a b]
    [c d]
```
この行列では、`ad-bc`が0でなければ逆行列があります。

```text
A⁻¹ = 1/(ad-bc) × [ d -b]
                       [-c  a]
```
`ad-bc`を行列式と呼びます。
行列式が0なら、空間を押しつぶして情報を失うため、逆行列を作れません。

大規模な計算では、逆行列そのものを求めるより、後で学ぶ消去法などで連立方程式を直接解く方が、速く安定な場合があります。

### 10 テンソル――さらに多くの方向へ並べた数

画像のように、行と列だけでは足りないデータもあります。
並べる方向の数で、スカラー、ベクトル、行列との関係を整理します。

```text
スカラー：0方向に広がる一個の数
ベクトル：1方向に並ぶ数
行列：2方向、つまり行と列に並ぶ数
テンソル：一般に、さらに多くの方向へ並ぶ数
```
カラー画像1枚は、高さ、幅、色の3成分という3方向に数が並んだテンソルとして扱えます。

複数枚をまとめると、画像番号、高さ、幅、色の4方向になります。

機械学習用ライブラリでは、多次元配列を広くテンソルと呼びます。
数学での厳密なテンソルは、座標を変えたときの変換規則まで含む概念ですが、初学段階では「多方向に並ぶ数の集まり」という入口から始めて構いません。

## 方程式と変換の性質を調べる

### 11 連立方程式を行列で書く

次の2つの式を同時に満たす`x,y`を求めます。

```text
2x + y = 5
x - y = 1
```
係数を行列にまとめます。

```text
[2  1][x] = [5]
[1 -1][y]   [1]
```
行列とベクトルに名前を付けると、次の形になります。

```text
Ax=b
```
`A⁻¹`があれば左から掛け、次のように解けます。

```text
A⁻¹Ax = A⁻¹b
Ix = A⁻¹b
x = A⁻¹b
```
ここで太字でない`x`は、実際には複数の未知数を並べたベクトルを表しています。

### 12 ガウスの消去法――式を少しずつ簡単にする

先ほどの連立方程式を解きます。

```text
2x + y = 5    …(1)
 x - y = 1    …(2)
```
式(2)を2倍します。

```text
2x - 2y = 2
```
式(1)から引くと、`x`が消えます。

```text
(2x+y) - (2x-2y) = 5-2
3y = 3
y = 1
```
求めた`y=1`を式(2)へ戻すと、`x`も決まります。

```text
x - 1 = 1
x = 2
```
ガウスの消去法は、この「ある式の何倍かを別の式に足し、未知数を1つずつ消す」作業を、行列に規則的に行います。

#### 拡大係数行列

式の係数と右辺だけを並べます。

```text
[2  1 | 5]
[1 -1 | 1]
```
行に対して、次の操作をしても解は変わりません。

- 2つの行を入れ替える。
- 1つの行を0でない数倍する。
- 1つの行の何倍かを、別の行に足す。

最終的に階段状にし、下の式から順に未知数を決めることを後退代入と呼びます。

#### ピボット選択

ある値で割るとき、その値をピボットと呼びます。
ピボットが0なら割れません。
非常に小さい値でも、丸め誤差が大きくなる恐れがあります。

そこで、下の行も含めて絶対値が大きい値を持つ行と入れ替える部分ピボット選択を行うことがあります。
数学上同じ答えでも、計算手順により数値的な安定性が違います。

### 13 固有ベクトル――変換しても向きが変わらない方向

連立方程式では、行列が作る変換を逆向きにたどりました。
今度は、その変換の性質が最も単純に現れる方向を探します。

行列`A`は、ベクトルを別のベクトルに変えます。
普通は、長さも向きも変わります。

特別な非零ベクトル`v`では、行列を掛けた結果が、元のベクトルの`λ`倍になります。
正の`λ`なら向きを保って長さが`λ`倍になり、負の`λ`なら向きが反転します。

```text
Av = λv
```
`v`を**固有ベクトル**、`λ`を**固有値**と呼びます。
`λ`はラムダと読みます。

#### 小さな例

```text
A = [2 0]
    [0 3]
```
横向きのベクトル`v=(1,0)`に掛けます。

```text
Av = (2,0) = 2v
```
向きは横のまま、長さが2倍です。
したがって、`(1,0)`は固有ベクトル、`2`は対応する固有値です。

縦向きの`(0,1)`では、次のようになります。

```text
A(0,1) = (0,3) = 3(0,1)
```
この方向の固有値は3です。

#### なぜ役立つのか

固有方向ごとに何倍されるかが分かると、繰り返し変換した先を理解しやすくなります。
次の用途などに使われます。

- マルコフ過程の定常分布。
- 主成分分析で、ばらつきが大きい方向を探す。
- 振動しやすい形や周波数を調べる。
- Webページの重要度を求める一部の方法。

固有値を求める際は、次の方程式を解きます。

```text
det(A-λI)=0
```
`det`は行列式を求める記号です。
式の導出を暗記するより、固有値は「その固有方向を何倍するか」と理解してください。

### 内積と固有値の条件を補う

内積からコサイン類似度を求めるときは、零ベクトルを除いて計算しました。
固有ベクトルの定義`Av=λv`では、`v≠0`が必須です。
`I`は対角成分が1、他が0の**単位行列**で、固有値は`det(A-λI)=0`から求めます。
例えば、

```text
A = [2 0]
    [0 3]

det(A-λI) = (2-λ)(3-λ) = 0
```
よって固有値は2と3です。
λ=2では`(A-2I)v=0`から`v=(1,0)`の定数倍、λ=3では`v=(0,1)`の定数倍が固有ベクトルです。

## 順番に変わる値を式で表す

### 14 数列――規則に従って並ぶ数

行列で一度に変換するのに対し、前の値から次の値を作る繰り返しもあります。
順番に並んだ数を、**数列**と呼びます。

```text
1, 3, 5, 7, 9, ...
```
各数を項と呼び、最初から`n`番目の項を`aₙ`と書きます。

#### 一般項

この数列の`n`番目の値は、次の一つの式で表せます。

```text
aₙ = 2n-1
```
この式を一般項と呼びます。

#### 漸化式

前の項から次の項を決める書き方もあります。

```text
a₁=1
aₙ₊₁=aₙ+2
```
これを漸化式と呼びます。
プログラムの繰返し処理に近い書き方です。

### 15 等差数列――同じ数を足し続ける

```text
3, 7, 11, 15, ...
```
隣どうしの差は常に4です。
このような数列を等差数列と呼びます。

最初の項`a=3`、公差`d=4`の場合、`n`番目の項は次のとおりです。

```text
aₙ = a + (n-1)d
```
最初の項から、4を`n-1`回足すからです。

最初から`n`番目までの和も、次の式で求められます。

```text
Sₙ = n(a₁+aₙ)÷2
```
先頭と末尾、二番目と末尾の1つ前を組にすると、どの組も同じ和になることから導けます。

### 16 等比数列――同じ数を掛け続ける

```text
2, 6, 18, 54, ...
```
前の項を3倍すると次の項になります。
このような数列を等比数列と呼び、掛ける数を公比と呼びます。

最初の項`a=2`、公比`r=3`の場合、一般項は次の式です。

```text
aₙ = arⁿ⁻¹
```
等比数列は、複利、指数的な増加、毎回一定割合で減る誤差などに現れます。

`r≠1`のとき、最初から`n`番目までの和は次のとおりです。

```text
Sₙ = a(1-rⁿ)÷(1-r)
```
式の符号を逆にして、`a(rⁿ-1)÷(r-1)`と書いても同じです。

### 17 フィボナッチ数列――前の二項を足す

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```
最初の2項以外は、直前の2項を足します。

```text
F₀=0
F₁=1
Fₙ=Fₙ₋₁+Fₙ₋₂
```
再帰処理の教材としてよく登場します。
定義をそのまま再帰プログラムにすると、同じ値を何度も計算して遅くなります。
計算済みの値を保存するメモ化や、前から順に一度ずつ計算する動的計画法を使うと効率化できます。

## 角度と式の関係を読む

### 18 三角関数――角度と辺の長さを結ぶ

直角三角形を考えます。
注目する角を`θ`とします。
`θ`はシータと読み、角度を表す文字としてよく使います。

- 斜辺：直角の向かい側にある最も長い辺。
- 対辺：`θ`の向かい側の辺。
- 隣辺：`θ`に接する辺のうち、斜辺でない方。

```text
sin θ = 対辺 ÷ 斜辺
cos θ = 隣辺 ÷ 斜辺
tan θ = 対辺 ÷ 隣辺
```
`sin`はサイン、`cos`はコサイン、`tan`はタンジェントと読みます。

#### なぜITで使うのか

- 画面上で物体を回転する。
- 音や電波の周期的な波を表す。
- ロボットの腕の先端位置を求める。
- 3次元CGの光と面の角度を計算する。

角度には度数法と弧度法があります。

```text
180度 = πラジアン
360度 = 2πラジアン
```
微分やプログラムの数学関数は、ラジアンを使うことが多いので、単位を確認します。

### 19 恒等式と方程式を区別する

次の式は、どの`θ`でも成り立ちます。

```text
sin²θ + cos²θ = 1
```
このように、変数に入れられるすべての値で成り立つ式を恒等式と呼びます。

一方、次の式を考えます。

```text
2x+1=7
```
これは`x=3`のときだけ成り立つ方程式です。

「いつでも成り立つ関係」なのか、「成り立つ値を探す問題」なのかを区別します。

## 観測と変化から数値解を求める

### 20 解析的に解くことと、数値的に解くこと

`2x+1=7`なら、式を変形して`x=3`と正確に求められます。
このように、有限の記号操作で厳密な形の答えを得ることを**解析的に解く**と呼びます。

ところが、現実の式には、きれいな形で解けないものや、解けても計算が非常に重いものがあります。

その場合、コンピュータで少しずつ答えに近づく数値解法を使います。

```text
厳密解：正確な記号や式で表した答え
数値解：小数などで得た近似的な答え
```
近似は「でたらめ」ではありません。
誤差を評価し、必要な精度を満たした答えです。

### 21 補間――分かっている点の間を推定する

時刻0秒で温度10℃、時刻2秒で温度18℃だったとします。
1秒時点を測り忘れました。

2点を直線で結ぶと仮定すると、ちょうど中間なので14℃と推定できます。

これを線形補間と呼びます。

2点`(x₀,y₀)`と`(x₁,y₁)`の間では、`x`に対応する値を次の式で推定します。

```text
y = y₀ + (y₁-y₀) × (x-x₀) ÷ (x₁-x₀)
```
この式は、次の三段階の計算です。

1. 全体の横幅に対し、どこまで進んだかという割合を求める。
2. 縦の変化量にその割合を掛ける。
3. 最初の高さに足す。

#### 補間と外挿

- 補間：観測した点の間を推定する。
- 外挿：観測範囲の外を推定する。

外挿は、観測範囲の外でも同じ傾向が続くと仮定するため、一般に危険が大きくなります。

#### 多項式補間とスプライン補間

多くの点を1つの高次多項式で通すと、点の間で大きく振動することがあります。
区間ごとに低次の多項式を使い、境目を滑らかにつなぐ方法がスプライン補間です。

補間法は、滑らかさ、計算量、端での振舞い、データのノイズを考えて選びます。

### 22 常微分方程式――変化の速さから未来を求める

観測済みの点の間を推定するだけでなく、変化率から将来の値を求めることもできます。
水槽の水量`y`が1秒ごとに一定の速さ`3`で増える関係を、次の式で表します。

```text
dy/dt = 3
```
`dy/dt`は、「時間`t`が少し進んだとき、水量`y`がどれほど変わるか」という変化率です。

変化率と現在値の関係を表す式を微分方程式と呼びます。
1つの**独立変数**についての通常の微分だけを含むものを常微分方程式と呼びます。
未知の関数は従属変数であり、複数個あっても独立変数が1つなら連立常微分方程式になり得ます。
複数の独立変数について偏微分を含むものは偏微分方程式です。

物体の運動、温度変化、人口、在庫、電気回路など、現実の変化を表すために使います。

### 23 オイラー法――今の傾きで、少し先へ進む

次の微分方程式を考えます。

```text
dy/dt = y
y(0)=1
```
「現在の値と同じ速さで増える」という意味です。

刻み幅を`h=0.1`とします。
現在の傾きに刻み幅を掛け、現在値に足します。

```text
次の値 = 現在値 + 刻み幅 × 現在の傾き
```
最初は`t=0, y=1`なので、傾きも1です。

```text
y(0.1) ≈ 1 + 0.1×1 = 1.1
```
次は、`y=1.1`なので傾きも1.1です。

```text
y(0.2) ≈ 1.1 + 0.1×1.1 = 1.21
```
これがオイラー法です。

#### 刻み幅の影響

刻み幅を小さくすると、普通は曲線を細かく追えて誤差が減ります。
ただし、刻み幅を小さくすると計算回数が増え、丸め誤差も蓄積します。

また、急激に変化する問題や不安定な問題では、単純なオイラー法が大きく外れることがあります。
改良オイラー法やルンゲ・クッタ法など、より精度や安定性の高い方法を使います。

## 積分を図形の和で近似する

### 24 数値積分を「面積の足し算」として復習する

曲線`y=f(x)`の下の面積を求めたいとします。
積分記号では、次のように表します。

```text
∫ₐᵇ f(x) dx
```
厳密な積分が難しいとき、区間を細く分け、簡単な図形の面積を足します。

### 25 台形則――曲線を直線で結ぶ

区間`[a,b]`の両端の高さを`f(a), f(b)`とします。
2点を直線で結び、台形の面積にします。

```text
面積 ≈ (b-a) × {f(a)+f(b)} ÷ 2
```
区間を複数に分ける複合台形則では、各小区間の台形を足します。

曲線が大きく曲がる区間では、直線近似の誤差が大きくなります。

### 26 シンプソン法――三点を放物線で結ぶ

シンプソン法は、区間の左端、中央、右端の3点を通る2次式、つまり放物線で曲線を近似します。

区間の幅を`2h`とし、3点を`x₀,x₁,x₂`とすると、次の式で近似できます。

```text
面積 ≈ h/3 × {f(x₀) + 4f(x₁) + f(x₂)}
```
中央の高さに4を掛けることが特徴です。

#### 例：`f(x)=x²`を0から2まで積分する

```text
x₀=0, x₁=1, x₂=2, h=1
f(0)=0, f(1)=1, f(2)=4
```
値を代入すると、次の結果になります。

```text
1/3 × (0 + 4×1 + 4)
= 8/3
```
2次式に対しては、この例では厳密な値と一致します。

複合シンプソン法では、小区間の個数を偶数にする必要があります。
適用条件を確認してください。

## 計算した桁の確かさを判断する

### 27 誤差の次数――刻みを半分にしたら、どれほど良くなるか

数値解法には、刻み幅`h`を小さくしたとき、誤差がどの速さで減るかという性質があります。

誤差がだいたい`h`に比例する方法なら、`h`を半分にすると誤差は約半分です。
誤差が`h²`に比例する方法なら、`h`を半分にすると誤差は約4分の1です。

これを収束次数で表します。

ただし、理論どおりになるのは、問題が必要な滑らかさを持ち、丸め誤差が支配的でなく、十分細かい範囲に入った場合です。

### 28 条件数――入力の小さな誤差が答えへ何倍響くか

どれほど優れた計算法でも、問題そのものが誤差に非常に敏感なら、正確な答えを得にくくなります。

入力の相対誤差が、出力の相対誤差におよそ何倍に増幅され得るかを表す指標を条件数と呼びます。

- 条件数が1に近い：比較的安定。
- 条件数が非常に大きい：小さな入力誤差が大きく増幅される恐れ。

「問題の悪条件性」と「計算法の不安定性」は分けて考えます。

- 悪条件：問題自体が敏感。
- 数値的不安定：計算法が不要に誤差を増やす。

測定値に誤差がある現実では、答えの桁を必要以上に表示しても、正確になったことにはなりません。

### 29 数式処理――数値ではなく記号のまま計算する

電卓は、`2+3`を5にします。
数式処理システムは、文字を含む式を記号のまま変形できます。

```text
(x+1)² → x²+2x+1
x²-1 → (x-1)(x+1)
d/dx (x³) → 3x²
∫ 2x dx → x² + C
```
このような処理を記号計算、または数式処理と呼びます。

式の展開、因数分解、簡単化、方程式の解法、微分と積分、行列の記号計算などに使えます。
数値を代入せずに、数式の性質を調べることもできます。

#### 数式処理の注意

式変形には、変数の範囲や分母が0でないことなどの条件があります。

たとえば、次の約分を考えます。

```text
x/x = 1
```
この関係は`x≠0`のときだけ成り立ちます。
`x=0`なら、左辺は0で割るため定義できません。

コンピュータが返した簡単な式だけでなく、その式が成り立つ条件も確認します。

また、数式処理で得た厳密な式が巨大になり、数値計算より扱いにくい場合もあります。
記号計算と数値計算を目的に応じて使い分けます。

### 30 数値解析の安全確認表

計算結果を受け取ったら、次を確認します。

1. 入力の単位は一致しているか。
2. 適用した公式や解法の前提を満たすか。
3. 刻み幅や停止条件は十分か。
4. 刻み幅を半分にしても、結果がほぼ変わらないか。
5. 別の解法でも近い値になるか。
6. 元の式に代入し、残差が小さいか。
7. 答えの符号や大きさは、現実的か。
8. オーバフロー、アンダフロー、丸め、桁落ちはないか。
9. 入力誤差に対して問題が敏感でないか。
10. 必要以上の桁を「正確」として報告していないか。

残差とは、近似解を元の式に入れたときの食い違いです。
悪条件問題では、残差が小さくても解そのものの誤差が大きいことがあるため、条件数も考えます。
`(3,2)`と`(2,3)`を区別したように、計算する値だけでなく、その対応や条件を保って初めて、結果の意味を判断できます。
