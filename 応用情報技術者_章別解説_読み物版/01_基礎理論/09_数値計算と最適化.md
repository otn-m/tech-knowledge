# 第1章9 数値計算と最適化――ぴったり解けない問題へ近づく


## この授業で分かること

- 関数、変化率、面積を計算へ結び付ける方法。
- 数式だけで解きにくい問題を近似する数値計算。
- 誤差と収束を確認する必要。
- 制約の中で最善を探す最適化。
- 複数の数をベクトルと行列でまとめる方法。

## 1 関数は「入力から出力を決める規則」

一個120円の商品を`x`個買うと、代金`y`円は次の規則で決まります。

```text
y = 120x
```

`x`へ値を入れると、`y`が一つに決まります。

```text
x=1 → y=120
x=2 → y=240
x=3 → y=360
```

このように、入力を一つ決めると出力が一つ決まる対応を**関数**と呼びます。

```text
y = f(x)
```

`f`は関数へ付けた名前で、`f(x)`は「xを関数fへ入れた結果」と読みます。`f×x`という掛け算ではありません。

## 2 変化の速さを見る微分

自動車の移動距離を時間ごとに測ります。

```text
時刻0秒  距離0m
時刻2秒  距離10m
```

二秒間の平均の速さは次のとおりです。

```text
距離の変化 ÷ 時間の変化
= (10-0)m ÷ (2-0)秒
= 5m/秒
```

グラフでは、二点を結ぶ線の傾きです。

時間幅を2秒から1秒、0.1秒、0.01秒と小さくすると、ある瞬間の変化の速さへ近づけられます。この極限として瞬間の変化率を求める考えが**微分**です。

関数`y=f(x)`の微分を、`f'(x)`や`dy/dx`などと書きます。

### y=x²の変化率

`x`から`x+h`までの平均変化率を求めます。`h`は小さな横の変化です。

```text
((x+h)²-x²) / h
```

`h`は0へ近付けますが、約分する段階では`h≠0`です。途中を省かず展開します。

```text
((x+h)²-x²)/h
= (x²+2xh+h²-x²)/h       分配して展開
= (2xh+h²)/h              同類項x²を消す
= h(2x+h)/h               hをくくる
= 2x+h                    h≠0なので約分
→ 2x                      最後にh→0
```

括弧を展開します。

```text
(x²+2xh+h²-x²)/h
=(2xh+h²)/h
=2x+h
```

`h`を0へ近づけると、`2x+h`は`2x`へ近づきます。したがって`y=x²`の変化率は`2x`です。

微分は、速度、増加率、曲線の傾き、損失を小さくする方向などに使われます。

## 3 小さな面積を足す積分

速度が時間で変わるとき、移動距離を求めたいとします。時間を小区間へ分け、各区間の速度を一定とみなせば、「速度×時間」で小さな距離を求められます。

```text
各区間の距離 ≈ 区間の速度 × 区間の時間
全距離 ≈ 各区間の距離を全部足す
```

区間を細かくし、その和の極限を考えるのが**積分**です。グラフでは、曲線と横軸の間の符号付き面積に対応します。

微分が「細かな変化を見る」操作なら、積分は「細かな量を集める」操作です。一定の条件下で、微分と積分は互いに逆向きの関係を持ちます。

## 4 数値計算が必要になる理由

すべての方程式や積分を、有限回の式変形だけで正確に解けるとは限りません。また、解の公式があっても計算が巨大になる場合があります。

そこで、コンピュータで繰り返し計算し、必要な精度の近似解を求めます。この方法を**数値計算**と呼びます。

近似には、必ず次の問いが伴います。

- 正しい答えへ近づいているか。
- 誤差はどの程度か。
- 何回で止めるか。
- 浮動小数点の丸め誤差が増えていないか。
- 入力のわずかな差で答えが大きく変わらないか。

## 5 二分法で方程式の解を探す

`f(x)=x²-2`が0になるx、つまり`x²=2`の正の解を探します。

```text
f(1)=1²-2=-1
f(2)=2²-2=2
```

1では負、2では正です。関数が途中で飛ばず連続なら、1と2の間に0を通る場所があります。

中点1.5を調べます。

```text
f(1.5)=2.25-2=0.25  正
```

負だった1と、正だった1.5の間へ範囲を狭めます。

```text
[1,2] → [1,1.5]
```

次の中点1.25を調べます。

```text
f(1.25)=1.5625-2=-0.4375  負
```

今度は`[1.25,1.5]`へ狭めます。これを繰り返す方法が**二分法**です。

各回で範囲が半分になるため確実に狭まります。ただし、両端で符号が異なること、間で連続であることなどの前提があります。偶数回接して戻る根などは単純な符号変化では見つからない場合があります。

## 6 ニュートン法

現在の点で曲線へ接線を引き、その接線が横軸と交わる場所を次の候補にする方法が**ニュートン法**です。

方程式`f(x)=0`について、次の式で更新します。

```text
xの次の値 = x - f(x)/f'(x)
```

`f'(x)`はその点の傾きです。傾きで関数値を割ると、接線上で横へどれだけ戻れば0へ着くかが分かります。

`f(x)=x²-2`、`f'(x)=2x`で、初期値2から始めます。

```text
x₁ = 2 - (2²-2)/(2×2)
   = 2 - 2/4
   = 1.5
```

次は次のとおりです。

```text
x₂ = 1.5 - (1.5²-2)/(2×1.5)
   = 1.5 - 0.25/3
   ≈ 1.4167
```

`√2≈1.4142`へ速く近づきます。

ただし、傾きが0に近い、初期値が悪い、複数の根がある場合などに、発散したり別の根へ進んだりします。速さだけでなく収束条件を見ます。

## 7 台形則で面積を近似する

曲線`y=x²`の0から2までの面積を近似します。幅1で二区間に分けます。

```text
x=0 → y=0
x=1 → y=1
x=2 → y=4
```

各区間で曲線の両端を直線で結び、台形として面積を求めます。

台形の面積は次のとおりです。

```text
幅 × (左の高さ+右の高さ) ÷ 2
```

```text
0～1: 1×(0+1)÷2 = 0.5
1～2: 1×(1+4)÷2 = 2.5
合計: 3
```

比較用の厳密値は、`x²`の原始関数が`x³/3`であることを使い、`[x³/3]₀²=2³/3-0³/3=8/3≈2.667`と求めます。積分法を未学習なら、この値は比較用に与えたものとして扱います。区間を細かくすると、各区間で曲線と直線のずれが小さくなり、通常は近似が改善します。

ただし細かくし続ければ無条件に完璧になるわけではありません。計算量が増え、浮動小数点の丸め誤差も積み重なります。

## 8 誤差を分けて考える

数値計算の誤差には複数の原因があります。

### 打切り誤差

本来無限に続ける操作を有限回で止めたり、曲線を直線で近似したりすることで生じます。

### 丸め誤差

有限桁の浮動小数点へ保存することで生じます。

### 入力誤差

測定値自体に含まれるずれです。正確な計算法も、入力以上の確かさを作れません。

### 絶対誤差と相対誤差

```text
絶対誤差 = |近似値-真値|
相対誤差 = 絶対誤差/|真値|
```

相対誤差は`真値≠0`のときだけこの式で定義できます。真値0では0除算になるため、絶対誤差を示すか、用途に定めた基準値・尺度で正規化します。

1メートルの誤差は、1000キロメートルの測定では小さく、2メートルの測定では巨大です。値の大きさに対する割合が相対誤差です。

## 9 収束と停止条件

繰返し計算の結果が、ある値へ近づくことを**収束**と呼びます。遠ざかったり振動し続けたりすることが発散です。

停止条件には次のようなものがあります。

- 前回と今回の差が許容値より小さい。
- 関数値`|f(x)|`が許容値より小さい。
- 区間幅が許容値より小さい。
- 最大反復回数へ達した。

差が小さくなっただけで、正しい解へ到達したとは限りません。最大反復回数は無限ループを防ぎますが、その時点の値が十分正確かを別に確認します。

## 10 最適化――制約の中で目的を最善にする

工場で製品AとBを作ります。材料と作業時間には限りがあり、利益を最大にしたいとします。

何を最大または最小にしたいかを表す式が**目的関数**です。使える材料、時間、予算などの条件が**制約条件**です。

```text
目的: 利益を最大にする
制約: 材料使用量は在庫以下
      作業時間は一日8時間以下
      生産数は0以上
```

制約を満たす候補全体を実行可能領域と呼びます。最適解は、その領域内で目的関数が最もよい点です。

## 11 線形計画法

目的関数と制約条件が一次式で表される最適化が**線形計画法**です。

例えば利益`Z=3x+2y`を、`x+y≤4`、`x≤2`、`x≥0`、`y≥0`の下で最大化します。実行可能領域の頂点は`(0,0)`、`(2,0)`、`(2,2)`、`(0,4)`です。

| 頂点 | `Z=3x+2y` |
|---|---:|
| `(0,0)` | 0 |
| `(2,0)` | 6 |
| `(2,2)` | 10 |
| `(0,4)` | 8 |

全頂点を比較すると最大は`(x,y)=(2,2)`、最大利益は10です。線形目的関数は、実行可能解が存在して有限な最適値を持つなら、少なくとも一つの頂点で最適になります。整数制約がある場合は連続解をそのまま丸めず、整数実行可能解を調べます。

製品Aを`x`個、Bを`y`個作るとします。

```text
利益を最大化: 300x + 200y

材料制約: 2x + y ≤ 8
時間制約: x + 2y ≤ 8
非負条件: x≥0, y≥0
```

二変数なら、各制約をグラフへ描き、すべてを満たす重なりを見つけられます。線形の目的関数は、実行可能領域の頂点のいずれかで最適になります。各頂点へ利益式を代入して比較します。

変数が多い場合はシンプレックス法や内点法などを使います。製品を0.5個作れないように整数条件が必要なら整数計画問題となり、難しさが増します。

## 12 局所最適と大域最適

山が複数ある地形で、現在地から上り続けると近くの山頂へ着きます。しかし別の場所にもっと高い山があるかもしれません。

周囲と比べて最善の点が**局所最適解**、候補全体で最善の点が**大域最適解**です。

勾配に従って進む方法は局所解へ到達しやすく、初期値で結果が変わる場合があります。問題の形が凸であれば、局所最適が大域最適になるなど扱いやすい性質があります。

厳密な最適解が必要か、十分よい解を期限内に得ればよいかも要件です。近似アルゴリズムやヒューリスティックを使う場合は、速さと解の品質を評価します。

## 13 ベクトル――複数の数を一組として扱う

平面上の点を、横と縦の二数で表します。

```text
(3,2)
```

複数の数を順序付きでまとめたものを**ベクトル**と呼びます。

二つの移動を足せます。

```text
(3,2) + (1,-1)
= (3+1, 2-1)
= (4,1)
```

各成分を同じ位置同士で計算します。

## 14 行列――数を長方形に並べる

数を行と列へ並べたものが**行列**です。

```text
┌ 0 -1 ┐
└ 1  0 ┘
```

この行列を点`(3,2)`へ掛けます。上の行とベクトル、下の行とベクトルをそれぞれ掛けて足します。

```text
新しい横 = 0×3 + (-1)×2 = -2
新しい縦 = 1×3 + 0×2    =  3
```

結果は`(-2,3)`です。点`(3,2)`を原点の周りに反時計回りへ90度回転した位置です。

行列を使うと、回転、拡大、連立方程式、データ変換などを共通の計算で扱えます。

### 行列の掛け算で順番が重要

行列Aの後にBを適用することと、Bの後にAを適用することは、一般に結果が違います。

```text
AB ≠ BA の場合がある
```

回転してから移動するのと、移動してから回転するのでは最終位置が違うことを考えると分かります。
