# 第3章　ハードウェアとコンピュータ構成要素――箱の中で何が動いているのか


## このファイルで初めて使う用語

本文で使う前に、ここでは次の意味を置きます。略語は正式名、日本語名、本文での役割の順です。

- **パイプライン**：複数命令の段階を重ね、流れ作業で処理する方式。（[詳説](<09_システム開発技術/29_DevOps・SRE・MLOps.md#17 CIパイプライン>)）
- **マルチコア**：一つのCPUパッケージ内に複数の処理コアを持つ構成。（[詳説](<03_ハードウェアとコンピュータ構成要素/06_並列処理とマルチプロセッサ.md#2 コア>)）
- **RAM**：Random Access Memory（随時読書きメモリ）。読書きでき、通常は電源を切ると内容が失われる半導体メモリ。（[詳説](<03_ハードウェアとコンピュータ構成要素/07_半導体メモリ.md#3 RAM>)）
- **ROM**：Read Only Memory（読出し専用メモリ）。内容を保持し、読出し中心で使うメモリ。（[詳説](<03_ハードウェアとコンピュータ構成要素/07_半導体メモリ.md#4 ROM>)）
- **バス**：CPU、メモリ、入出力装置の間で、データや制御信号を運ぶ共通経路。（[詳説](<03_ハードウェアとコンピュータ構成要素/10_バスと接続規格.md#第3章・第10話　バスと接続規格――部品の間を走る共用道路>)）
- **DMA**：Direct Memory Access（直接メモリアクセス）。CPUが一件ずつ運ばず、装置と主記憶の間でまとめてデータ転送する仕組み。（[詳説](<03_ハードウェアとコンピュータ構成要素/11_入出力インタフェースとDMA.md#24 DMA>)）
- **スループット**：単位時間に処理できる仕事量。（[詳説](<03_ハードウェアとコンピュータ構成要素/05_CPU性能とパイプライン.md#11 レイテンシとスループット>)）
- **デバイスドライバ**：OSから特定機器を操作するためのソフトウェア。（[詳説](<03_ハードウェアとコンピュータ構成要素/11_入出力インタフェースとDMA.md#29 デバイスドライバ>)）


この章では、パソコンの箱を開けたことがなくても分かるところから始めます。

コンピュータは、正体不明の魔法の箱ではありません。入力されたものを受け取り、決められた手順で計算し、途中結果を覚え、結果を外へ出す装置です。その仕事を実際に行うCPU、メモリ、記憶装置、バス、入出力装置、電子回路を、一つずつ見ていきます。

部品名だけを暗記する章ではありません。ボタンを押してから画面へ結果が出るまで、命令とデータがどこを通り、どこで待ち、何が速さや故障しにくさを左右するのかを追えるようになることが目標です。

## この章で身に付けること

読み終えると、次を自分の言葉で説明し、紙の上で小さな計算ができることを目標にします。

- コンピュータの五大装置と、データ・制御の流れを説明する。
- CPUの命令取出しから実行までを、レジスタの変化とともに追う。
- アドレス指定を使って、実際に参照する番地を計算する。
- 割込み、マイクロプログラム、パイプラインの目的を説明する。
- クロック、CPI、MIPS、FLOPSから処理時間を計算する。
- 並列処理の速さと限界を、アムダールの法則で計算する。
- RAM、ROM、キャッシュ、HDD、SSD、光ディスク、磁気テープを使い分ける。
- キャッシュのヒット率と実効アクセス時間を計算する。
- バスの幅・周波数・転送回数から帯域を計算する。
- DMA、デバイスドライバ、接続規格の役割を説明する。
- 入力・表示・印刷・音声装置が現実の量とデジタル値を変換する仕組みを説明する。
- 論理回路、フリップフロップ、半導体、組込み制御、低消費電力設計の基礎を説明する。

## 応用情報技術者試験での扱われ方

- **典型設問:** 「第1話から順番に読みます。」
- **条件語:** `パイプライン`を本文の定義と対応させます。
- **最初の着眼点:** 初期状態と終了条件を置き、状態が変わるたびに値や主体を一行ずつ記録します。
- **途中の組立て・式:** 入力→判定→更新→出力の順を追い、分岐と例外でも同じ規則が保たれるか確かめます。 対象→入力→処理→出力の流れと、成立条件・限界を対応させます。選択問題でも不採用案が条件へ反する箇所を示します。
- **典型誤答と理由:** 処理名を暗記しただけでは、順序の逆転、更新前後の値、失敗後に残る状態を取り違えます。

## 学習の進め方

1. 第1話から順番に読みます。
2. 部品が出たら、「何を受け取るか」「何をするか」「何を渡すか」の三つを書きます。
3. 計算では、Hz、秒、ビット、バイトなどの単位を省略しません。
4. 各話の確認問題は、模範解答と照合し、自分の誤答がどの用語・条件・単位の取り違えから生じたか説明します。選択式の総合問題では、不採用選択肢の誤りも説明します。
5. 第16話は20問ずつ四回に分け、翌日に間違えた問題だけを解き直します。

この章の部品は、単独では働きません。CPUが命令を取り、キャッシュになければ主記憶へ行き、バスを使って装置へ指示し、割込みやDMAで結果を受け取る――この一続きの物語として理解してください。
