# 第3章 第16話 総合演習

カメラが取り込んだ1枚の画像は、入力装置からDMAで主記憶へ入り、キャッシュを経てCPUやGPUで処理され、画面へ出ます。
経路のどこか1か所でも帯域、同期、期限、安全性の条件を満たさなければ、各部品が単独で高性能でも装置は正しく動きません。

総合問題では、CPU、記憶、バス、入出力、電子回路を別々の暗記として扱わず、データと制御が移る順に結びます。

計算ではHz、秒、バイト、ビットを式の各値に付けます。
単位が途中で消え、求める単位だけが残るかを確認すると、換算や分母の誤りを見つけられます。

## 五段階到達度演習

次の1つの題材を、条件を変えながら5段階で解きます。
後の段階ほど、前段階の答えを使わなければ解けません。

**共通ケース**： 画像解析装置はCPU、キャッシュ、主記憶、SSD、GPUを使い、毎秒60枚を期限内に処理する。

| 段階 | 実際に求める行動 |
|---|---|
| 第1段階 思い出す | 用語を定義し、対象と役割を再現する。 |
| 第2段階 まねる | 与えた値と手順で、途中状態、式、単位を省略せず再現する。 |
| 第3段階 見分ける | 似た概念を、対象、時点、目的、失敗条件の比較軸で区別する。 |
| 第4段階 使う | 同じ題材の条件変更に知識を適用し、代替案との比較から判断する。 |
| 第5段階 試験水準 | 3つ以上の知識を統合し、前提、計算、設計、失敗時、検証基準まで示す。 |

### 到達度1｜第1段階 思い出す

CPU、キャッシュ、主記憶、SSD、GPUの役割を、この装置でデータが通る順を意識して1文ずつ答えてください。

### 到達度2｜第2段階 まねる

1枚が1920×1080画素、1画素3バイトの画像を毎秒60枚読む。

### 到達度3｜第3段階 見分ける

キャッシュミスでCPUが待つ問題と、SSDから主記憶への転送帯域不足を区別してください。
観測すべき指標と、有効な改善策を1つずつ答えてください。

### 到達度4｜第4段階 使う

転送時間を無視した理論上の全体高速化率をAmdahlの法則で求め、GPUだけの増強が十分か判断してください。

### 到達度5｜第5段階 試験水準

毎秒60枚、99.9%の期限内完了、単一SSD故障でも継続という条件で構成を選び、帯域、CPU/GPU時間、記憶階層、冗長化、熱と消費電力の検証方法まで示してください。

## 解答編

計算解答は、`数値×単位`を各入力に付け、割算、換算で消える単位と最後に残る単位を示します。
GHzは`10⁹回/s`、nsは`10⁻⁹s`、KiBは`2¹⁰B`として途中でそろえます。

## Aの解答

### 解1

温度センサーが入力、モーターと表示が出力、設定温度、プログラムを置くメモリが記憶、実温度との差を計算するALUが演算、どの順に読みモーターに指示するか決めるCPU制御部が制御です。

### 解2

デスクトップは拡張、冷却、サーバは連続稼働、冗長、遠隔管理、組込みは期限、電力、費用、安全、スーパーコンピュータは大規模並列、通信、冷却を重視します。

### 解3

PCは次の命令の住所、IRは今の命令、MARはアクセス住所、DRは運ぶデータです。
