# 技術日本語の最終校正

このプロジェクトの日本語の技術文書や教材を対象とする。
他の日本語スキルで構成と文体を整えたあと、以下の観点で最終校正する。
局所的な校正だけを求められた場合は、依頼された範囲を点検する。

## 校正の範囲

事実、数値、例、条件、因果、論理の順序、用語の定義、断定の強さを保つ。
診断だけを求められた場合はファイルを編集しない。
編集時も、対象範囲、原本の保持、別ファイルへの保存などの指定を守る。
構成の変更、文体の統一、リズムの演出は、この校正では行わない。

## 点検項目

1. **助詞と係り受け**
   主語と述語、目的語と動詞、修飾語と被修飾語の対応を確かめる。
   「差へ1を足す」は「差に1を足す」のように、動詞に合う助詞へ直す。
   対象の補足が必要な場合は、前後に明示されている名詞だけを使う。

2. **連語と語の選択**
   「ここでは次の意味を置きます」は「ここでは次の意味で使います」のように、同じ内容を表す自然な連語へ直す。
   専門用語を平易な語へ変える場合も、概念の範囲を広げたり狭めたりしない。

3. **数量表記と数え方**
   具体的な数量は原則として「8ビット」「1バイト」「4通り」と書く。
   「一方」「一般」「二進数」などの熟語や定着した用語は機械的に変換せず、文書に明示された表記規則を優先する。
   「二状態」は「2つの状態」、「二状態なら」は「状態が2つなら」のように、助数詞と助詞を補う。
   助数詞や単位を直すときは、対象が個数、段階、組み合わせのどれを表すかを文脈から確定する。
   「100個の電圧」を「100段階の電圧」へ変えてよいのは、元の説明が電圧の段階を指していると確認できる場合に限る。
   数量の意味が不明な場合は、推測で直さず確認事項として報告する。

4. **用語と語義の一貫性**
   定義、本文、例、問題、解答で、同じ用語が同じ対象を指しているか確かめる。
   用語欄の「スイッチ」がネットワーク機器、本文の「スイッチ」が照明器具を指す場合は、対象を区別できる表現を検討する。
   定義や説明内容の修正が必要なら、校正へ混ぜず不整合として報告する。

## 最小修正と内容不変の確認

対象箇所と前後の段落を読み、その箇所が伝える命題、条件、確実性、用語の意味を確認する。
数量表記と用語は、文書内の定義や既存の表記にも照らす。
1語で直せるなら1文を書き換えず、1文で済むなら段落を組み替えない。
修正後は前後を通読し、次の点を原文と照合する。

- 数値、固有名、例、条件、例外が同じである。
- 断定、可能性、推量、義務の強さが同じである。
- 原因と結果、比較対象、否定対象、論理の順序が同じである。
- 用語が指す対象と概念の範囲が同じである。
- 主張、評価、説明上の情報を追加も削除もしていない。

満たさない修正は戻し、より小さな変更にする。
意味を保った修正案が作れない場合は、本文を変えず問題点を報告する。
修正不要な箇所はそのまま残す。

## 報告

診断では、場所、原文、問題の種類、理由、最小修正案を示す。
編集では、変更した範囲と、内容不変の確認結果を簡潔に報告する。
内容の判断が必要な問題は、校正結果と区別して示す。
